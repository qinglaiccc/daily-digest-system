# GitHub 热门效率与 AI 工具

*让普通人也能用上 AI 与效率工具，从终端到桌面全覆盖。*

**t4t5/omdrop-owl**

★2.5k · Shell · 近期趋势

让 Linux 电脑也能和 iPhone 互传文件，像苹果设备之间那样隔空投送。

**核心亮点**

- 在 iPhone 和 Linux 电脑之间互传文件
- 支持 Wi-Fi 保持连接的共享模式
- 可切换为独占模式提高可见性

**应用与部署指南**

需要先安装 omdrop-owl 包，再安装 omdrop 插件。Arch/Omarchy 用户可用 yay 安装，Debian/Ubuntu 用户需从源码构建 deb 包。

- [ ] Arch/Omarchy 用户执行 yay -S omdrop-owl
- [ ] Debian/Ubuntu 用户先安装依赖包
- [ ] 运行 tools/build-deb.sh 构建 deb 包
- [ ] 安装生成的 deb 包
- [ ] 安装 omdrop 插件并启用

```bash
yay -S omdrop-owl
```

[查看仓库](https://github.com/t4t5/omdrop-owl)

**storytold/effectcraft**

★5.8k · Rust · 近期趋势

免费开源的视频特效和动画制作工具，类似 After Effects，可在电脑或浏览器里用。

**核心亮点**

- 用图层和关键帧制作动画
- 内置 306 种特效和图层样式
- 支持 3D 摄像机和灯光
- 可导出渲染队列

**应用与部署指南**

提供 macOS、Windows、Linux 桌面版和浏览器版，具体安装方式请查看官网下载页面。

- [ ] 访问官网 getartcraft.com 下载对应版本

[查看仓库](https://github.com/storytold/effectcraft)

**Wox-launcher/Wox**

★27.5k · Go

跨平台的快速启动器，按快捷键就能搜应用、找文件、执行操作，类似 Alfred。

**核心亮点**

- 键盘优先，快速打开应用和文件
- 支持插件扩展功能
- 内存占用约 150MB，轻量常驻

**应用与部署指南**

支持 Windows、macOS、Linux，可通过 Homebrew、Winget、Scoop 等包管理器安装，或从官网下载。

- [ ] macOS 用户执行 brew install --cask wox
- [ ] Windows 用户执行 winget install -e --id Wox.Wox
- [ ] 或从官网下载安装包

```bash
brew install --cask wox
```

[查看仓库](https://github.com/Wox-launcher/Wox)

**google-gemini/gemini-cli**

★107.3k · TypeScript

在终端里直接使用谷歌 Gemini AI 的开源工具，能回答问题、操作文件、执行命令。

**核心亮点**

- 免费额度：每分钟 60 次请求
- 支持谷歌搜索、文件操作和 shell 命令
- 可通过 MCP 协议扩展自定义功能

**应用与部署指南**

需要 Node.js 环境，可用 npx 直接运行，或全局安装。使用个人谷歌账号登录即可获得免费额度。

- [ ] 确保已安装 Node.js
- [ ] 运行 npx @google/gemini-cli 直接使用
- [ ] 或执行 npm install -g @google/gemini-cli 全局安装

```bash
npx @google/gemini-cli
```

[查看仓库](https://github.com/google-gemini/gemini-cli)

**pytorch/pytorch**

★104.7k · Python

一个用 Python 做深度学习和科学计算的工具库，能利用显卡加速运算。

**核心亮点**

- 像 NumPy 一样做张量计算，但支持 GPU 加速
- 自动求导，方便搭建神经网络
- 可复用 NumPy、SciPy 等 Python 库

**应用与部署指南**

需要 Python 环境，可通过 pip 或 conda 安装，也提供 Docker 镜像。具体安装命令请参考官网。

- [ ] 安装 Python 环境
- [ ] 访问 pytorch.org 获取安装命令
- [ ] 按官网指引执行安装

[查看仓库](https://github.com/pytorch/pytorch)
