**rddmwmddr/android-ad-cleaner**

★3.2k · Python · 近期趋势

给国产安卓手机一键关掉系统广告和营销推送，不用 root，还能还原。

**核心亮点**

- 按渠道勾选要关的营销通知
- 自动检测手机型号和广告组件
- 每一步可还原，系统更新不受影响
- 支持 AI 智能体一键执行

**应用与部署指南**

在电脑上下载对应系统的桌面客户端，用数据线连上手机并开启 USB 调试，按界面提示点几下即可，不需要装 Python。

- [ ] 从 Releases 下载对应系统的桌面客户端
- [ ] 用数据线连接手机并开启 USB 调试
- [ ] 打开客户端检测手机和广告组件
- [ ] 勾选要关闭的项目后执行

[查看仓库](https://github.com/rddmwmddr/android-ad-cleaner)

**KnifeLemon/Filee**

★14.7k · C# · 近期趋势

拖拽文件就能离线转换格式的工具，不用上传、不用装 Office。

**核心亮点**

- 支持 263 种格式互转
- 拖到光标处松手即转换
- 全程离线，文件不上传
- 结果保存在原文件旁边

**应用与部署指南**

从 Releases 下载安装包，Windows 双击 exe 安装，macOS 解压后运行 install.sh；装好后按住 Ctrl 拖文件到弹出的格式圈即可。

- [ ] 从 Releases 下载对应系统安装包
- [ ] Windows 运行 Setup.exe 安装
- [ ] macOS 解压后运行 ./install.sh
- [ ] 按住 Ctrl 拖文件到格式圈转换

[查看仓库](https://github.com/KnifeLemon/Filee)

**Wox-launcher/Wox**

★27.6k · Go

一个键盘呼出的桌面启动器，快速打开应用、找文件、执行操作。

**核心亮点**

- 键盘输入即可打开应用和文件
- 支持插件扩展功能
- 常驻后台占用约 150MB 内存
- Windows、macOS、Linux 都能用

**应用与部署指南**

用系统包管理器安装，比如 macOS 用 Homebrew、Windows 用 Winget，装好后用快捷键呼出输入框即可使用。

- [ ] macOS 执行 brew install --cask wox
- [ ] Windows 执行 winget install -e --id Wox.Wox
- [ ] 用快捷键呼出输入框开始使用

```bash
brew install --cask wox
```

[查看仓库](https://github.com/Wox-launcher/Wox)
