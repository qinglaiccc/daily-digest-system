# GitHub 热门效率与 AI 工具

*从本地文件搜索到 AI 对话界面，这批工具让电脑更懂你。*

**Minireel/HGhub**

★2.3k · TypeScript · 近期趋势

一个能看短剧的第三方播放器，支持电脑和安卓手机。

**核心亮点**

- 在 Windows、macOS 和安卓上刷短剧
- 竖屏沉浸式播放，像刷短视频一样
- 自动缓存封面和播放列表，加载更快

**应用与部署指南**

去 GitHub Releases 下载对应系统的安装包，双击安装即可使用。项目不提供内容，只作为浏览第三方站点的客户端。

- [ ] 打开 GitHub Releases 页面
- [ ] 下载对应系统的安装包
- [ ] 安装后打开，以访客身份浏览

[查看仓库](https://github.com/Minireel/HGhub)

**ARahim3/DigUp**

★6.3k · Swift · 近期趋势

用一句话描述你想找的东西，就能搜出电脑里的图片、视频和文档。

**核心亮点**

- 按内容搜文件，不只靠文件名
- 能搜图片、PDF、录音和视频
- 支持 100 多种语言互相搜索

**应用与部署指南**

从官网或 GitHub 下载 Mac、Windows 或 Linux 版安装包，打开后选择要搜索的文件夹，再用自己的话描述想找的内容即可。所有处理都在本机完成。

- [ ] 从官网下载对应系统的安装包
- [ ] 安装后打开应用
- [ ] 选择要搜索的文件夹
- [ ] 用一句话描述想找的内容

[查看仓库](https://github.com/ARahim3/DigUp)

**alyssaxuu/screenity**

★19k · JavaScript

一个免费无限制的录屏工具，还能在画面上涂鸦做标注。

**核心亮点**

- 录制整个屏幕、某个区域或摄像头
- 边录边在画面上画箭头、写字
- 录制麦克风声音或电脑内部声音

**应用与部署指南**

这是一个浏览器扩展，在 Chrome 应用商店安装后点击图标即可开始录制。无需安装额外软件，录制内容保存在本地。

- [ ] 在 Chrome 应用商店搜索 Screenity
- [ ] 点击安装扩展
- [ ] 点击扩展图标开始录制

[查看仓库](https://github.com/alyssaxuu/screenity)

**open-webui/open-webui**

★158k · Svelte

一个可以自己搭建的 AI 聊天网页，能连本地或云端的大模型。

**核心亮点**

- 像用 ChatGPT 一样和 AI 对话
- 可以连接本地运行的模型，数据不出门
- 支持多种模型和插件扩展

**应用与部署指南**

需要先装 Python 3.12 或 Docker。用 pip 安装后运行命令，浏览器打开 localhost:8080 即可使用；用 Docker 则打开 localhost:3000。

- [ ] 安装 Python 3.12 或 Docker
- [ ] 运行 pip install open-webui
- [ ] 运行 open-webui serve
- [ ] 浏览器打开 http://localhost:8080

```bash
pip install open-webui
```

[查看仓库](https://github.com/open-webui/open-webui)

**langchain-ai/langchain**

★149.2k · Python

帮开发者把 AI 模型和外部工具串起来，做出能自动干活的程序。

**核心亮点**

- 把 AI 模型和搜索、数据库等工具连起来
- 提供现成组件，减少重复写代码
- 支持多种主流 AI 模型

**应用与部署指南**

这是给开发者用的编程工具，需要会 Python。先安装 uv 包管理工具，再用它安装 langchain，然后写代码调用模型。

- [ ] 安装 uv 包管理工具
- [ ] 运行 uv add langchain
- [ ] 在代码中导入并调用模型

```bash
uv add langchain
```

[查看仓库](https://github.com/langchain-ai/langchain)
