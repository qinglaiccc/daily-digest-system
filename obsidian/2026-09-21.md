**mizorewww/laya-mlx**

★1.6k · Python · 近期趋势

在苹果电脑上本地做快速分类判断的小模型，不用联网也不生成文字。

**核心亮点**

- 本地运行，不上传数据到云端
- 毫秒级给出分类结果
- 不生成文字，只做选择判断

**应用与部署指南**

需要苹果芯片的 Mac、Python 3.11 以上和 macOS 14 以上。用 pip 安装后加载模型即可在本地调用，首次会下载模型文件。

- [ ] 确认使用苹果芯片 Mac 与 Python 3.11+
- [ ] pip install laya-mlx
- [ ] import laya_mlx as laya
- [ ] agent = laya.load("aac6fef/laya-mlx")

[查看仓库](https://github.com/mizorewww/laya-mlx)
