# GitHub 热门效率与 AI 工具

*让网页角色动起来、拆解视频、快速启动应用、省AI费用、搭后端*

**livliv-dev/player**

★1.5k · TypeScript · 近期趋势

在网页里放一个会动、会说话、能跟着你表情变化的虚拟角色。

**核心亮点**

- 几行代码把角色放进网页或直播画面
- 麦克风或视频声音自动对口型
- 摄像头捕捉你的表情同步到角色
- 自带21个不同风格角色可直接用

**应用与部署指南**

需要先装 Node.js，然后在项目里安装这个播放器包，用几行代码就能把角色显示在网页画布上；也可以直接打开官方在线示例先试玩。

- [ ] 先安装 Node.js 环境
- [ ] 运行 npm install @livliv-dev/player
- [ ] 在代码里引入 Player 并绑定画布
- [ ] 打开示例页面查看效果

```bash
npm install @livliv-dev/player
```

[查看仓库](https://github.com/livliv-dev/player)

**JuneYaooo/rea-video**

★7.1k · Python · 近期趋势

把一段视频拆成一个个镜头，告诉你哪些是实拍、哪些是AI生成、哪些是代码做的，并给出复刻方案。

**核心亮点**

- 逐镜头判断视频是实拍还是AI生成
- 生成一份完整的复刻计划
- 输出带截图和证据的网页报告
- 分析背景音乐和节奏

**应用与部署指南**

需要先装好 ffmpeg 和 Python 3.10 以上，然后在 Claude Code 等能执行命令的 AI 助手里说一句话，它会自动安装并分析你给的视频文件。

- [ ] 安装 ffmpeg（如 brew install ffmpeg）
- [ ] 克隆仓库并进入目录
- [ ] 运行 bash scripts/install_skill.sh
- [ ] 在 AI 助手里让它分析视频路径

```bash
bash scripts/install_skill.sh
```

[查看仓库](https://github.com/JuneYaooo/rea-video)

**Wox-launcher/Wox**

★27.6k · Go

一个按键盘就能快速打开软件、找文件、执行操作的启动器，Windows、Mac、Linux 都能用。

**核心亮点**

- 敲几个字就能打开应用或文件
- 全程键盘操作不用鼠标
- 支持安装插件扩展功能
- 后台常驻只占约150MB内存

**应用与部署指南**

直接下载安装包或用系统包管理器安装即可，装好后用快捷键呼出输入框，输入想找的东西就能用，不需要额外配置。

- [ ] macOS 用户运行 brew install --cask wox
- [ ] Windows 用户运行 winget install -e --id Wox.Wox
- [ ] 装好后用快捷键呼出搜索框

```bash
brew install --cask wox
```

[查看仓库](https://github.com/Wox-launcher/Wox)
