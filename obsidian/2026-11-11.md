**IainKay/ram-altman**

★1.8k · Shell · 近期趋势

一个恶搞脚本：每天给 OpenAI 老板发邮件，汇报你电脑里闲置的内存。

**核心亮点**

- 统计内存总量、已用和可用容量
- 可用内存超 10% 就每天发一封邮件
- 轮换标题和落款，让玩笑不重复
- 把每次采样记录成 CSV 文件

**应用与部署指南**

这是个 Shell 脚本，需要在 Linux 上运行，并配置好能发邮件的环境；不想装的话，官网直接看示例邮件即可。

- [ ] 准备一台 Linux 电脑并配置好邮件发送
- [ ] 从仓库下载脚本并赋予执行权限
- [ ] 用 cron 设置每天自动运行一次

[查看仓库](https://github.com/IainKay/ram-altman)

**rddmwmddr/android-ad-cleaner**

★7.4k · Python · 近期趋势

帮国产安卓手机关掉系统里的广告、热搜和资讯推送，不用 root，还能还原。

**核心亮点**

- 一键关闭系统广告和营销推送
- 不用 root，改动可以还原
- 提供 Mac、Windows 和手机客户端
- 支持 AI 智能体一键执行

**应用与部署指南**

下载对应系统的客户端，插上手机点几下按钮即可，不需要装 Python；手机版可直接在安卓 11 以上安装使用。

- [ ] 从 Releases 下载对应系统的客户端
- [ ] Mac 用户按芯片选 Apple 或 Intel 版本
- [ ] Windows 弹安全提示时点仍要运行
- [ ] 连接手机后按界面提示点按钮执行

[查看仓库](https://github.com/rddmwmddr/android-ad-cleaner)

**Flow-Launcher/Flow.Launcher**

★16k · C#

Windows 上的快速搜索启动器，按快捷键就能找应用、文件和网页内容。

**核心亮点**

- 快速搜索应用和文件
- 支持社区插件扩展功能
- 可搜索书签、YouTube 等网络内容
- 提供安装版和免安装版

**应用与部署指南**

- [ ] 安装完成后用快捷键呼出搜索框

```bash

```
