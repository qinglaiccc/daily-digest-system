# GitHub 热门效率与 AI 工具

*从炒股辅助到修图、搜文件、读代码，这批工具都在帮人省时间。*

**Jakeschincariol/day-trader-skill**

★2.1k · Python · 近期趋势

给 Claude 装的 11 个炒股小助手，帮你看图、追新闻、算买卖点，先模拟再动真钱。

**核心亮点**

- 一次扫描上千张股票走势图找机会
- 盯住你关注的股票突发新闻
- 逐根K线提示进场时机与止损目标
- 用历史数据回放，先看胜率再下单

**应用与部署指南**

需要先有 Claude 或 Claude Code。免费、无需注册和 API Key，数据来自公开渠道；默认只做模拟交易，任何下单都要你亲口同意。

- [ ] 准备好 Claude 或 Claude Code 环境
- [ ] 在 Claude 中粘贴仓库地址并说 install skill
- [ ] 或在 Claude Code 执行 /plugin marketplace add Jakeschincariol/day-trader-skill
- [ ] 再执行 /plugin install day-trader-skill@day-trader-skill

```bash
/plugin marketplace add Jakeschincariol/day-trader-skill
```

[查看仓库](https://github.com/Jakeschincariol/day-trader-skill)

**storytold/lightcraft**

★14.8k · Rust · 近期趋势

一款免费开源的修图软件，专治 RAW 照片，改多少都不伤原图。

**核心亮点**

- 调曝光、对比度、高光阴影等基础参数
- 支持蒙版和预设，局部精修
- 照片库管理，原图永不改动
- 可在电脑本地或浏览器里使用

**应用与部署指南**

提供 macOS、Windows、Linux 原生安装包，也能在浏览器里通过网页版使用；README 未给出命令行安装方式，建议从官网下载页获取。

- [ ] 打开官网 getartcraft.com 的下载页
- [ ] 按你的系统选择对应安装包
- [ ] 安装后导入照片即可开始修图

[查看仓库](https://github.com/storytold/lightcraft)

**Flow-Launcher/Flow.Launcher**

★15.9k · C#

Windows 上的快捷启动器，敲几下键盘就能找到软件、文件和网页书签。

**核心亮点**

- 搜索应用、文件和文件内容
- 支持网页搜索与浏览器书签
- 可用社区插件扩展功能
- 支持自定义快捷键呼出

**应用与部署指南**

仅支持 Windows 10 及以上。可用安装包或便携版，也能通过 winget、Scoop、Chocolatey 命令行安装；首次安装可能弹出未签名安全提示，从本仓库下载可继续。

- [ ] 确认系统为 Windows 10 或更高版本
- [ ] 执行 winget install "Flow Launcher"
- [ ] 或执行 scoop install Flow-Launcher
- [ ] 安装后按快捷键呼出搜索框

```bash
winget install "Flow Launcher"
```

[查看仓库](https://github.com/Flow-Launcher/Flow.Launcher)

**Graphify-Labs/graphify**

★136.1k · Python

把整个代码项目画成一张可查询的关系图，让 AI 助手不用翻文件就能读懂。

**核心亮点**

- 把代码、文档、PDF 整理成知识图谱
- 每条关联标注是直接读到还是推断的
- 代码解析全在本地完成，不上传
- 在 AI 助手里输入 /graphify 即可调用

**应用与部署指南**

这是给 Claude Code、Cursor、Codex、Gemini CLI 等 AI 编程助手用的技能，需先装好对应助手；README 摘录未给出具体安装命令，建议按仓库文档操作。

- [ ] 先安装并登录一个支持的 AI 编程助手
- [ ] 在助手中输入 /graphify 调用该技能

[查看仓库](https://github.com/Graphify-Labs/graphify)
