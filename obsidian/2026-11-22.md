# GitHub 热门效率与 AI 工具

*让视频剪辑、看片、写作、用 AI 和写代码都更省事的开源工具*

**iamajmeena/neonclipping**

★1.7k · Python · 近期趋势

粘贴视频链接，两分钟自动剪出带字幕的竖屏短片，全程在自己电脑上跑。

**核心亮点**

- 粘贴 YouTube、Twitch 等链接自动剪出竖屏片段
- 自动生成字幕、标题和开场钩子
- 支持游戏画面的人脸摄像头自动布局
- 全程本地运行，不上传、不注册、不花钱

**应用与部署指南**

需要先装好 Python 环境，Windows 用户可下载一键 .bat 脚本，Mac/Linux 用 install.sh 安装，之后在本地运行，无需账号和 API Key。

- [ ] Windows 下载并运行一键 .bat 安装脚本
- [ ] Mac/Linux 运行 install.sh 完成安装
- [ ] 启动程序后粘贴视频链接
- [ ] 等待约两分钟获取带字幕的竖屏片段

```bash
install.sh
```

[查看仓库](https://github.com/iamajmeena/neonclipping)

**Minireel/HGhub**

★11k · Rust · 近期趋势

一个靠插件接入内容的视频播放器，把浏览、搜索、播放和收藏放在同一个应用里。

**核心亮点**

- 导入插件后接入不同内容来源
- 统一界面浏览、搜索和播放
- 管理本地收藏、历史与续播进度
- 支持直播、信息流和图文内容

**应用与部署指南**

目前处于早期开发阶段，需从源码运行或自行构建，重点支持 Windows 和 Android；首次使用要自己导入插件，应用不内置内容源。

- [ ] 从源码运行或按文档自行构建客户端
- [ ] 打开插件中心进入导入与订阅
- [ ] 选择插件文件或粘贴插件网址并启用
- [ ] 从首页或搜索找到内容开始播放

[查看仓库](https://github.com/Minireel/HGhub)

**Zettlr/Zettlr**

★14k · TypeScript

面向写作者的桌面写作工具，从记笔记到导出成稿一站式完成。

**核心亮点**

- 笔记默认保存在本地，注重隐私
- 对接 Zotero 等文献管理工具做引用
- 支持 LaTeX 和 Word 模板排版
- 一键导出多种发布格式

**应用与部署指南**

提供各平台安装包，从官网下载安装即可使用；想从源码构建则需按文档准备开发环境。

- [ ] 访问官网下载对应系统安装包
- [ ] 安装后打开应用开始写作
- [ ] 在设置中连接文献管理工具
- [ ] 用导出功能生成发布文件

[查看仓库](https://github.com/Zettlr/Zettlr)

**open-webui/open-webui**

★159.2k · Svelte

给 AI 大模型套上一个好用的网页界面，可以完全离线自己部署。

**核心亮点**

- 连接本地或云端的大模型
- 在浏览器里像聊天软件一样对话
- 可完全离线运行，数据不出本机
- 支持多种模型来源切换

**应用与部署指南**

需要先装 Docker 或 Python 3.12，用一条命令启动后在浏览器打开本地地址即可使用；连本地模型需先装好 Ollama。

- [ ] 先安装 Docker 或 Python 3.12
- [ ] 运行 docker run 启动服务
- [ ] 浏览器打开 http://localhost:3000
- [ ] 按需连接 Ollama 或兼容 API

```bash
docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui --restart always ghcr.io/open-webui/open-webui:main
```

[查看仓库](https://github.com/open-webui/open-webui)

面向使用 AI 编程助手的人，需按官方文档安装工具包并接入自己的编程助手，具体命令以文档为准。

- [ ] 按官方文档安装 Spec Kit 工具包
- [ ] 接入你常用的 AI 编程助手
- [ ] 选择规格开发、修 Bug 或评估流程
- [ ] 按模板逐步推进并记录结果
