# GitHub 热门效率与 AI 工具

*让 AI 帮你画图、读代码、克隆应用，把重复劳动交给机器。*

**Jakeschincariol/replica-skill**

★1.6k · Python · 近期趋势

一套让 AI 照着别人的 App 重做一个、还能顺手改掉用户吐槽点的工具包。

**核心亮点**

- 拆解目标 App 的功能和流程
- 照着重建一个能用的版本
- 自动找 bug 并修掉用户抱怨
- 生成品牌名和落地页文案

**应用与部署指南**

在 Claude 里粘贴仓库地址并说 install skill 即可；用 Claude Code 的话可以按插件方式装。不需要注册、不需要 API Key。

- [ ] 在 Claude 中粘贴仓库链接并输入 install skill
- [ ] 或执行 /plugin marketplace add Jakeschincariol/replica-skill
- [ ] 再执行 /plugin install replica-skill@replica-skill

```bash
https://github.com/Jakeschincariol/replica-skill

install skill
```

[查看仓库](https://github.com/Jakeschincariol/replica-skill)

**storytold/pdfcraft**

★7.9k · Rust · 近期趋势

一个免费开源的 PDF 工具箱，能看、能合并拆分、能加密，对标 Adobe Acrobat。

**核心亮点**

- 阅读和查找 PDF 内容
- 合并、拆分、整理页面
- 给 PDF 加密码保护
- 支持表单和图层

**应用与部署指南**

提供 macOS、Windows、Linux、FreeBSD 和网页版，去官网或仓库下载对应版本安装即可，无需额外配置。

- [ ] 访问 getartcraft.com/apps/pdfcraft 下载对应系统版本
- [ ] 安装后打开即可使用

[查看仓库](https://github.com/storytold/pdfcraft)

**DayuanJiang/next-ai-draw-io**

★36.2k · TypeScript

用一句话描述，AI 就在 draw.io 画布上帮你画出流程图和架构图。

**核心亮点**

- 一句话生成架构图、流程图
- 选中图形让 AI 只改这部分
- 每次修改可对比、可撤销
- 导出为 drawio、png、svg

**应用与部署指南**

有网页版可直接用，也有 Windows/macOS/Linux 桌面版；还能作为 MCP 服务接入 Claude Code、Cursor 等工具。

- [ ] 访问 next-ai-drawio.jiang.jp 在线使用
- [ ] 或下载桌面版安装
- [ ] 或在 AI 编程工具中接入 MCP Server

[查看仓库](https://github.com/DayuanJiang/next-ai-draw-io)

**excalidraw/excalidraw**

★133.6k · TypeScript

一个手绘风格的白板工具，画流程图、草图都行，还能多人实时协作。

**核心亮点**

- 手绘风格画图，支持多种图形
- 多人实时协作，端到端加密
- 可离线使用，自动保存到浏览器
- 导出 PNG、SVG 或分享链接

**应用与部署指南**

直接打开 excalidraw.com 就能用，无需安装；想自己部署可以按仓库文档用 npm 包集成。

- [ ] 访问 excalidraw.com 即可开始画图
- [ ] 如需自建，参考仓库 Quick start 文档

[查看仓库](https://github.com/excalidraw/excalidraw)

**Graphify-Labs/graphify**

★125.3k · Python

把整个代码项目变成一张可查询的知识地图，让 AI 助手不用翻文件就能回答问题。

**核心亮点**

- 把代码、文档、PDF 变成知识图谱
- 每条连接都标明是直接读到还是推断的
- 本地解析代码，不上传机器
- 在 AI 助手里输入 /graphify 即可查询

**应用与部署指南**

在 Claude Code、Cursor、Codex 或 Gemini CLI 里输入 /graphify 就能用；代码解析全在本地，文档和 PDF 会用到 AI 模型。

- [ ] 在支持的 AI 编程助手中打开项目
- [ ] 输入 /graphify 命令
- [ ] 按提示等待生成知识图谱

[查看仓库](https://github.com/Graphify-Labs/graphify)
