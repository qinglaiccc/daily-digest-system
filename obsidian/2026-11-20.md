# GitHub 热门效率与 AI 工具

*让 AI 模型跑得更快、用得更容易，从本地加速到桌面应用。*

**sybil-solutions/inference-optimisation-skill**

★1.3k · Python · 近期趋势

教 AI 助手一步步调快本地大模型出字速度的实操手册。

**核心亮点**

- 提升单人及多人同时使用的出字速度
- 缩短启动时间和首字等待时间
- 在内存上限内优化并做长文本稳定性检查

**应用与部署指南**

这是给 AI 编程助手用的技能文件，需配合 Claude Code 等能加载 SKILL.md 的助手使用；没有助手也可按 PROMPT.md 手动照做。

- [ ] 准备一个能加载 SKILL.md 的 AI 助手（如 Claude Code）
- [ ] 让助手加载本项目的 SKILL.md 技能文件
- [ ] 按手册流程逐项调整并记录每次结果

[查看仓库](https://github.com/sybil-solutions/inference-optimisation-skill)

**RoutineMiku/apkstart**

★8.3k · JavaScript · 近期趋势

让 Windows 电脑双击安卓安装包就能像装普通软件一样用安卓应用。

**核心亮点**

- 双击 APK 自动安装并生成桌面图标
- 每个安卓应用独立窗口运行
- 开始菜单可搜索、任务栏按应用分组
- 电脑与安卓应用共享文件夹双向同步

**应用与部署指南**

去 GitHub 或 Gitee 的 Releases 页下载安装包，解压或安装后即可双击 APK 使用；不想编译就选完整便携版。

- [ ] 打开 GitHub 或 Gitee 的 Releases 页面
- [ ] 下载对应安装包（商店版/便携版/完整版）
- [ ] 解压或安装后双击 APK 即可运行

[查看仓库](https://github.com/RoutineMiku/apkstart)

**YishenTu/claudian**

★16k · TypeScript

把 AI 编程助手塞进笔记软件 Obsidian，让它在你的笔记库里读写和干活。

**核心亮点**

- AI 可直接读写、搜索笔记库文件
- 选中文字即可让 AI 就地改写并预览差异
- 可把多个会话编成项目共享记忆
- 支持斜杠命令和 @ 引用文件

**应用与部署指南**

这是 Obsidian 插件，需先安装 Obsidian，再从插件市场或手动安装本插件，并配置好要用的 AI 助手。

- [ ] 先安装 Obsidian 笔记软件
- [ ] 安装 Claudian 插件并启用
- [ ] 配置 Claude Code 等 AI 助手后使用

[查看仓库](https://github.com/YishenTu/claudian)

**huggingface/transformers**

★169.3k · Python

一个统一调用各种开源 AI 模型（文字、图片、语音）的 Python 工具库。

**核心亮点**

- 一个库调用上百万个预训练模型
- 覆盖文字、图像、音频、视频和多模态
- 同时支持模型推理和训练

**应用与部署指南**

需要 Python 3.11+ 和 PyTorch 2.6+，先建虚拟环境再安装；适合会写 Python 的人本地跑。

- [ ] 安装 Python 3.11 及以上版本
- [ ] 创建并激活虚拟环境
- [ ] 安装 PyTorch 2.6 及以上版本
- [ ] 安装 transformers 库

[查看仓库](https://github.com/huggingface/transformers)

**AUTOMATIC1111/stable-diffusion-webui**

★165.4k · Python

在浏览器里用文字生成图片的 Stable Diffusion 网页操作界面。

**核心亮点**

- 输入文字生成图片、用图片改图片
- 支持局部重绘和画面扩展
- 可修复人脸、放大图片
- 用括号给提示词加权重

**应用与部署指南**

需要先装 Python 和 Git，然后运行一键安装启动脚本，之后在浏览器里打开使用。

- [ ] 先安装 Python 和 Git
- [ ] 运行一键安装并启动脚本
- [ ] 在浏览器中打开界面开始生成图片

[查看仓库](https://github.com/AUTOMATIC1111/stable-diffusion-webui)
