**rtk-ai/rtk**

★80.3k · Rust

给 AI 编程助手装个过滤器，把命令输出压缩后再喂给它，省下大量费用。

**核心亮点**

- 压缩命令输出，减少 AI 读取的 token 量
- 支持 100 多种常用开发命令
- 单个可执行文件，无需额外依赖

**应用与部署指南**

在 Mac 上用 Homebrew 安装，Windows 用 winget，Linux 可用一键脚本。装好后作为代理运行，无需申请 API Key。

- [ ] brew install rtk

```bash
brew install rtk
```
