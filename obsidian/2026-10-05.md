# GitHub 热门效率与 AI 工具

*让 AI 更好用：写得更自然、聊得更聪明、邮件更省心、网页更好抓、提示词随手取。*

**nanaism/yomiyasu**

★1.4k · Python · 近期趋势

把 AI 写出来的生硬日语改得像人话，适合技术文章和报告。

**核心亮点**

- 修正主谓不明、指代不清的句子
- 去掉生硬的拟人化表达
- 保留原文意思，只改读不顺的地方

**应用与部署指南**

这是给 AI 编程助手用的技能包，需要先有 Codex、Claude Code 或 Cursor 等环境，把技能加载进去后让它帮你改日语文章。

- [ ] 准备 Codex、Claude Code 或 Cursor 环境
- [ ] 把 yomiyasu 技能加载进你的 AI 助手
- [ ] 把 AI 生成的日语文章交给它润色

[查看仓库](https://github.com/nanaism/yomiyasu)

**jev-chat/jev-chat-jarvis**

★7.3k · Kotlin · 近期趋势

手机上的聊天副驾，读懂对方消息并给出回复建议，发不发你决定。

**核心亮点**

- 分析对方真实意图和危险等级
- 给出三条排好序的候选回复
- 一键把回复填进输入框，不自动发送

**应用与部署指南**

下载 Android APK 安装（需 Android 11 以上、ARM64 手机），开启无障碍权限后即可在 QQ、X 等平台使用；也可用 Windows 或 macOS 版。

- [ ] 下载 Android 版 APK（需 Android 11+、ARM64）
- [ ] 安装后开启系统无障碍服务权限
- [ ] 在设置页配置判断、回复、视觉三路接口
- [ ] 打开聊天软件，悬浮窗会给出回复建议

[查看仓库](https://github.com/jev-chat/jev-chat-jarvis)

**elie222/inbox-zero**

★12.4k · TypeScript

帮你快速清空收件箱的 AI 邮件助手，自动整理、起草回复、管日程。

**核心亮点**

- 自动整理收件箱并按你的语气起草回复
- 用大白话写规则让 AI 处理邮件
- 一键退订并归档从不看的邮件
- 拦截冷邮件，自动把附件存到网盘

**应用与部署指南**

这是一个开源网页应用，可以自己部署，也可以直接用官方在线版；需要连接你的 Gmail 账号，并配置 AI 模型的接口密钥。

- [ ] 准备 Gmail 账号和 AI 模型 API Key
- [ ] 按官方文档部署或访问在线版
- [ ] 授权连接邮箱后开始使用

[查看仓库](https://github.com/elie222/inbox-zero)

**firecrawl/firecrawl**

★188.6k · TypeScript

把网页内容抓下来变成 AI 能直接读的干净文字，省去自己写爬虫。

**核心亮点**

- 把任意网址转成干净的 Markdown 或结构化数据
- 能抓需要 JavaScript 才显示的页面
- 支持搜索网页并直接拿到全文内容
- 能解析网页上的 PDF、DOCX 等文件

**应用与部署指南**

可以自己部署开源版，也可以直接用官方托管服务；自己部署需要一定的服务器环境，托管版注册后拿 API Key 即可调用。

- [ ] 选择自部署或使用官方托管服务
- [ ] 自部署需准备服务器环境并启动服务
- [ ] 托管版注册后获取 API Key
- [ ] 用 API Key 调用抓取或搜索接口

[查看仓库](https://github.com/firecrawl/firecrawl)
