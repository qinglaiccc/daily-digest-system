# GitHub 热门效率与 AI 工具

*让普通人也能用上 AI 助手、模型和提示词，把 AI 真正用起来。*

**JoasASantos/REA-Prompts**

★1.7k · 近期趋势

一套现成的提问模板，让 AI 帮你拆解软件是怎么做出来的。

**核心亮点**

- 覆盖游戏、手机应用、网页等多种软件
- 按主题分类，复制粘贴就能用
- 每个模板只聚焦一个功能，答案更靠谱

**应用与部署指南**

这是纯提示词合集，不需要安装任何软件。打开仓库找到对应章节，把模板复制到你的 AI 编程助手里，替换掉占位内容即可。

- [ ] 打开仓库，找到「Install & verify」章节
- [ ] 按需选择章节，复制其中的提示词模板
- [ ] 粘贴到 AI 编程助手中，替换占位内容后发送

[查看仓库](https://github.com/JoasASantos/REA-Prompts)

**yetone/magpie**

★20.2k · Go · 近期趋势

一个菜单栏小工具，让各种 AI 编程助手随意换用不同家的模型。

**核心亮点**

- 一个列表里给每个助手挑模型
- 一个账号或密钥在所有助手里通用
- 额度用完自动换下一个账号，不报错

**应用与部署指南**

从官网下载安装包，或在终端执行安装命令。支持 macOS、Windows、Linux，也有 Docker 和命令行版本。

- [ ] 从 usemagpie.ai 下载对应系统的安装包
- [ ] 或执行 README 中的安装命令
- [ ] 打开应用，在菜单栏选择要用的模型

[查看仓库](https://github.com/yetone/magpie)

**rowboatlabs/rowboat**

★18.1k · TypeScript

一个开源的私人 AI 助理，自带邮件、笔记和白板，能记住你的工作内容。

**核心亮点**

- 把邮件、会议、聊天整理成知识网络
- 内置邮件客户端，自动起草回复
- 可设定时或触发式后台任务
- 自带隔离浏览器，只登录你允许的账号

**应用与部署指南**

从官网下载 Mac、Windows 或 Linux 安装包，装好打开就能用，不需要自己配置服务器。

- [ ] 访问官网下载对应系统的安装包
- [ ] 安装并打开 Rowboat
- [ ] 按引导连接邮箱等账号即可使用

[查看仓库](https://github.com/rowboatlabs/rowboat)

**open-webui/open-webui**

★156.6k · Python

一个可以自己搭建的 AI 聊天网页，把各种大模型集中到一个界面里用。

**核心亮点**

- 完全离线运行，数据不出本机
- 同时接本地模型和云端模型接口
- 管理员可给不同人分配不同权限
- 支持插件扩展，接入外部工具

**应用与部署指南**

需要先装好 Python 或 Docker，用 pip、uv 或 Docker 一条命令启动，然后浏览器打开本地地址使用。

- [ ] 先安装 Docker 或 Python 环境
- [ ] 执行 README 中的安装命令启动服务
- [ ] 浏览器访问本地地址，注册账号开始使用

[查看仓库](https://github.com/open-webui/open-webui)

**langchain-ai/langchain**

★148.3k · Python

给开发者用的工具箱，把大模型和各种服务拼起来做成 AI 应用。

**核心亮点**

- 把模型、数据源和工具串成流程
- 内置大量第三方服务对接
- 配套工具可调试和部署 AI 应用

**应用与部署指南**

面向开发者，需要先装 Python 环境，用 uv 安装后写几行代码即可调用模型。

- [ ] 先安装 Python 和 uv 包管理工具
- [ ] 执行 uv add langchain 安装
- [ ] 写代码调用模型，运行验证

```bash
uv add langchain
```

[查看仓库](https://github.com/langchain-ai/langchain)
