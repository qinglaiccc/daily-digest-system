# GitHub 热门效率与 AI 工具

*让写代码、跑容器、记时间、配终端更省事，AI 帮你少写多做。*

**erkamyaman/rust-anything**

★1.2k · Rust · 近期趋势

把现有应用一块块改写成更快的 Rust 代码，每步都对照原程序行为验证。

**核心亮点**

- 先录下原程序的实际行为，改写后逐项比对
- 支持命令行工具、网页服务和代码库
- 可只把最慢的部分单独提速
- 改写由你的 AI 编程助手或你本人完成

**应用与部署指南**

需要先装好 Node 环境，再通过 npm 安装这个工具；它负责录制原程序行为并校验改写结果，Rust 代码由你或 AI 助手来写。

- [ ] 先安装 Node.js 环境
- [ ] 用 npm 安装 rust-anything 工具
- [ ] 录制原程序的行为作为对照
- [ ] 逐块改写并对照录制结果验证

```bash
npm install -g rust-anything
```

[查看仓库](https://github.com/erkamyaman/rust-anything)

**libracoder/kiri**

★10.1k · Rust · 近期趋势

一个轻量的容器运行工具，替代笨重的 Docker Desktop，跑现有镜像更快更省资源。

**核心亮点**

- 兼容你现有的 docker 命令和镜像
- 容器启动约 2.5 毫秒，比 Docker Desktop 快很多
- 空闲时自动休眠，占用内存小
- 自带本地域名和 HTTPS 证书
- 一条命令搭起 Kubernetes 集群

**应用与部署指南**

从官网或发布页下载对应系统的安装包，装好后用你熟悉的 docker 命令即可；支持 macOS、Windows 和 Linux。

- [ ] 从官网或 Releases 页下载安装包
- [ ] 按系统提示完成安装
- [ ] 用现有 docker 命令运行容器

[查看仓库](https://github.com/libracoder/kiri)

**ActivityWatch/activitywatch**

★19.7k · Python

自动记录你电脑上在用什么软件、看什么网页，帮你弄清时间花在哪，数据只存本地。

**核心亮点**

- 记录当前使用的应用和窗口标题
- 记录浏览器标签页标题和网址
- 根据键鼠活动判断你是否离开
- 数据存在本地，由你自己掌控

**应用与部署指南**

从官网或发布页下载对应系统的安装包，装好后在本地运行，数据保存在你自己电脑上，无需注册账号。

- [ ] 从官网或 Releases 页下载安装包
- [ ] 按系统提示完成安装
- [ ] 启动后打开本地面板查看记录

[查看仓库](https://github.com/ActivityWatch/activitywatch)

**ohmyzsh/ohmyzsh**

★190.8k · Shell

给命令行终端换上一套好用的配置和主题，让敲命令更顺手、界面更好看。

**核心亮点**

- 内置 300 多个可选插件
- 提供 140 多款终端主题
- 社区维护，配置可自由定制

**应用与部署指南**

需要先装好 zsh 和 git，然后用一条安装脚本命令装好，之后在终端里就能用上插件和主题。

- [ ] 先安装 zsh 和 git
- [ ] 运行官方安装脚本命令
- [ ] 按提示把默认终端切换为 zsh

[查看仓库](https://github.com/ohmyzsh/ohmyzsh)

**DietrichGebert/ponytail**

★193k · JavaScript

让 AI 编程助手像一位话少的老手，只写任务真正需要的代码，不堆砌。

**核心亮点**

- 让 AI 少写冗余代码，减少时间和花费
- 保留校验、错误处理和安全逻辑
- 可接入 Claude Code 等 AI 编程工具

**应用与部署指南**

把它作为技能或规则接入你用的 AI 编程助手（如 Claude Code），之后助手写代码时会按这套规则来。

- [ ] 准备一个可用的 AI 编程助手
- [ ] 按官网说明把 Ponytail 接入该助手
- [ ] 在对话中启用后正常让助手写代码

[查看仓库](https://github.com/DietrichGebert/ponytail)
