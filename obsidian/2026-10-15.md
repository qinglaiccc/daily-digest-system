# GitHub 热门效率与 AI 工具

*让电脑和 AI 更懂你的文件、数据与记忆，用起来更省心。*

**ARahim3/DigUp**

★3.6k · Swift · 近期趋势

用大白话描述就能搜到电脑里的照片、PDF、录音和视频，全部在本机运行。

**核心亮点**

- 按内容搜文件，不靠文件名
- 视频能跳到出现画面的那一刻
- 播客能跳到聊某个话题的分钟
- 支持一百多种语言互相搜索

**应用与部署指南**

Mac 可直接下载安装包，Windows 和 Linux 目前是测试版；所有处理都在本机完成，不需要联网或申请密钥。

- [ ] 从项目页面下载对应系统的安装包
- [ ] 打开软件，选择要搜索的文件夹
- [ ] 用日常语言描述想找的内容

[查看仓库](https://github.com/ARahim3/DigUp)

**shader-effects-inc/shaders**

★4.8k · TypeScript · 近期趋势

给网页加炫酷视觉特效的现成组件，不用自己写复杂图形代码。

**核心亮点**

- 两百多种特效直接当组件用
- 支持 React、Vue、Svelte 等框架
- 在线画布设计后导出代码
- 可搭配 AI 辅助生成效果

**应用与部署指南**

需要先装 Node.js，然后在项目里安装这个包，按框架引入对应组件即可；也可在官网画布上设计后导出代码。

- [ ] 先安装 Node.js 环境
- [ ] 在项目目录执行 npm install shaders
- [ ] 按所用框架引入组件并使用

```bash
npm install shaders
```

[查看仓库](https://github.com/shader-effects-inc/shaders)

**plotly/dash**

★24.4k · Python

用 Python 就能做出带图表和交互的数据网页，不用写 JavaScript。

**核心亮点**

- 下拉框滑块直接连到 Python 代码
- 支持约五十种图表含地图
- 可做出像报告一样的页面
- 代码简洁，几十行就能跑

**应用与部署指南**

需要先装 Python，然后用 pip 安装 Dash，写一个 Python 文件运行后浏览器打开即可看到页面。

- [ ] 先安装 Python 环境
- [ ] 用 pip 安装 Dash 库
- [ ] 写一个 Python 文件并运行
- [ ] 浏览器打开本地地址查看

[查看仓库](https://github.com/plotly/dash)

**thedotmack/claude-mem**

★100.8k · TypeScript

给 AI 助手装上长期记忆，换一次对话它还记得之前做过什么。

**核心亮点**

- 自动记录 AI 每次的操作
- 把记录压缩成摘要保存
- 下次对话自动带上相关记忆
- 支持 Claude Code 等工具

**应用与部署指南**

需要先装 Node.js，用 npx 命令安装到对应的 AI 工具里；默认使用云端记忆服务，也可选本地模式。

- [ ] 先安装 Node.js 环境
- [ ] 执行 npx claude-mem install --ide grok-bot
- [ ] 按提示完成配置后开始使用

```bash
npx claude-mem install --ide grok-bot
```

[查看仓库](https://github.com/thedotmack/claude-mem)
