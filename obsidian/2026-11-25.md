**xcl-dev/xcl**

★7.8k · Rust · 近期趋势

让 Xbox 主机游戏能在 Windows 电脑上直接运行的兼容层工具

**核心亮点**

- 在电脑上运行自己已购买的 Xbox 游戏
- 游戏代码原生运行，不靠模拟器
- 把主机画面代码转成电脑能用的格式
- 只支持已解包的游戏文件

**应用与部署指南**

需要自己准备已解包的游戏文件，项目不提供下载或解密游戏包；具体安装步骤 README 未写明，建议先看仓库说明和 Discord 社区。

- [ ] 准备自己已购买并解包好的游戏文件
- [ ] 阅读仓库说明了解当前支持的游戏列表

[查看仓库](https://github.com/xcl-dev/xcl)

**mdiri-ai/SoduWork**

★7.6k · JavaScript · 近期趋势

让多个 AI 助手分工干活、互相检查、由人最终确认的协作平台

**核心亮点**

- 一个 AI 干活，另一个 AI 按标准检查
- 可以把任务派给同事的 AI 助手
- 支持多种 AI 工具接入
- 可以部署在自己的服务器上

**应用与部署指南**

需要先装 Git、Python 3.12 和 Node.js 22，克隆代码后运行启动脚本即可，支持桌面模式。

- [ ] 安装 Git、Python 3.12.x 和 Node.js 22.x
- [ ] git clone https://github.com/mdiri-ai/SoduWork
- [ ] cd SoduWork
- [ ] sh start.sh --desktop

[查看仓库](https://github.com/mdiri-ai/SoduWork)

- 助手之间可以互相@和交接工作
- 共享白板、文档和任务清单
- 每一步都可见，人可随时介入

**应用与部署指南**

有网页版、App Store 应用和桌面版可选，也可以自带 AI 助手接入；具体安装命令 README 未给出。

- [ ] 访问官网或下载桌面版/App Store 应用
- [ ] 创建或接入自己的 AI 助手
- [ ] 把助手拉进群聊开始协作

[查看仓库](https://github.com/rowboatlabs/rowboat)
