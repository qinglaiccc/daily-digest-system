**wheresryan22/anatomy**

★3.2k · JavaScript · 近期趋势

让 AI 把抽象概念画成能动手操作的立体机械图，方便讲解复杂原理。

**核心亮点**

- 把技术概念变成可交互的立体机械图
- 生成的图能随鼠标和键盘动起来
- 图里每个数字都来自同一套模型

**应用与部署指南**

需要先装好 Claude Code、OpenCode 或 Codex 这类 AI 编程助手，再用一条命令把技能装进去，之后在对话里输入 /anatomy 加你的问题即可。

- [ ] 先安装 Claude Code 或 OpenCode、Codex
- [ ] 运行 npx skills add wheresryan22/anatomy -g -a claude-code
- [ ] 在 Claude Code 里输入 /anatomy 加要解释的概念

```bash
npx skills add wheresryan22/anatomy -g -a claude-code
```

[查看仓库](https://github.com/wheresryan22/anatomy)

★7.1k · Rust · 近期趋势

一个免费开源的矢量画图工具，对标 Adobe Illustrator，能在电脑和浏览器里用。

**核心亮点**

- 画矢量图，支持钢笔和贝塞尔曲线
- 图层、混合、透视网格都能实时编辑
- macOS、Windows、Linux 和浏览器都能跑

**应用与部署指南**

可以直接从官网下载安装包，在 macOS、Windows、Linux 或 FreeBSD 上本地运行，也能在浏览器里通过 WebAssembly 打开使用，无需额外配置。

- [ ] 访问官网 getartcraft.com/apps/vectorcraft
- [ ] 下载对应系统的安装包或直接在浏览器打开

[查看仓库](https://github.com/storytold/vectorcraft)

**Flow-Launcher/Flow.Launcher**

★15.7k · C#

Windows 上的快速搜索启动器，敲几个键就能找到应用、文件和网页书签。

**核心亮点**

- 搜索应用、文件和文件内容
- 支持浏览器书签和网页搜索
- 有社区做的各种插件可扩展

**应用与部署指南**

- [ ] 确认系统是 Windows 10 或更高版本
- [ ] 运行 winget install "Flow Launcher"
- [ ] 装好后按快捷键呼出搜索框使用

```bash
winget install "Flow Launcher"
```
