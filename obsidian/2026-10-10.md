# GitHub 热门效率与 AI 工具

*让 AI 与效率工具跑在自己手里：管钱、调模型、截图、写代码、画图。*

**LosaLosSantos/aurelio-finance**

★1.6k · Python · 近期趋势

装在自己电脑上的记账理财工具，还能跟 AI 顾问聊你的资产。

**核心亮点**

- 记录银行、券商账户里的现金和持仓
- 自动算每笔投资的成本、收益和分红
- 看清基金背后真正持有的国家和行业
- 可选 AI 顾问，用自己的密钥对话

**应用与部署指南**

需要先装 Git、Node.js 22 以上和 uv，然后在终端克隆项目并运行启动脚本；首次启动会自动装依赖并打开网页，先用演示数据试跑，去掉参数就用你自己的数据。

- [ ] 先安装 Git、Node.js 22+ 和 uv
- [ ] git clone https://github.com/LosaLosSantos/aurelio-finance.git
- [ ] cd aurelio-finance
- [ ] ./start.sh --demo

[查看仓库](https://github.com/LosaLosSantos/aurelio-finance)

**yetone/magpie**

★7.4k · Go · 近期趋势

一个菜单栏小工具，让各种 AI 编程助手随便换模型和账号。

**核心亮点**

- 从菜单栏给每个 AI 助手换模型
- 一个密钥在所有助手里通用
- 额度用完自动切到下一个账号
- 支持 macOS、Windows 和 Linux

**应用与部署指南**

从官网下载安装即可，支持菜单栏应用、窗口、网页和命令行多种用法；适合同时用多个 AI 助手或多套账号的人，只用一家官方套餐的话不需要它。

- [ ] 访问 usemagpie.ai 下载对应系统版本
- [ ] 安装后从菜单栏打开 magpie
- [ ] 在列表里为每个助手挑选模型

[查看仓库](https://github.com/yetone/magpie)

**ShareX/ShareX**

★40k · C#

Windows 上的免费截图录屏工具，截完还能直接编辑和上传。

**核心亮点**

- 一个快捷键截取屏幕任意区域
- 录屏或录成 GIF 动图
- 截图后直接标注、取色、识别文字
- 上传文件并自动复制分享链接

**应用与部署指南**

这是 Windows 桌面软件，从官网下载安装包安装即可，不需要注册账号；装好后设置快捷键就能开始截图、录屏和上传。

- [ ] 访问 getsharex.com 下载安装包
- [ ] 安装并启动 ShareX
- [ ] 设置截图快捷键后开始使用

[查看仓库](https://github.com/ShareX/ShareX)

**github/spec-kit**

★140.6k · Python

给 AI 编程助手定规矩的工具包，让它按流程写代码而不是乱写。

**核心亮点**

- 先写清需求再让 AI 动手开发
- 提供修 bug 和评估点子的固定流程
- 模板可复用，也能换成自己的流程

**应用与部署指南**

需要先装 Python 3.11 以上、uv 和一个受支持的 AI 编程助手，然后在终端安装命令行工具并初始化项目，示例默认用 GitHub Copilot。

- [ ] 先安装 Python 3.11+、uv 和 AI 编程助手
- [ ] uv tool install specify-cli
- [ ] specify init my-project --integration copilot
- [ ] cd my-project

[查看仓库](https://github.com/github/spec-kit)
