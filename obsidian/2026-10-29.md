# GitHub 热门效率与 AI 工具

*从背单词、画矢量图到搭个人主页、用 AI 写代码、训练模型，都是能上手用的工具。*

**designfuchen/word-atlas**

★3k · TypeScript · 近期趋势

把雅思单词配成插画和发音的背词应用，解决死记硬背记不住的问题。

**核心亮点**

- 个雅思词条，每个配插画和例句
- 英音美音切换，例句可朗读
- 按记忆规律自动安排复习时间
- 学习进度存本地，无需注册账号

**应用与部署指南**

可直接打开官网在线使用，也可本地运行开源版；进度存在自己设备上，换设备前记得先导出备份。

- [ ] 访问官网 0xlei.tech/words 直接体验
- [ ] 或按 README 本地运行开源版
- [ ] 换设备前先导出学习进度备份

[查看仓库](https://github.com/designfuchen/word-atlas)

**storytold/vectorcraft**

★10.9k · Rust · 近期趋势

一款开源的矢量画图工具，用来画图标、插画这类可无限放大的图形。

**核心亮点**

- 钢笔工具画曲线，可随时调整锚点
- 图层和混合效果实时可编辑
- 支持透视网格和尺寸标注
- 电脑本地运行，也能在浏览器里用

**应用与部署指南**

可从官网下载 macOS、Windows、Linux 版本安装，也能直接在浏览器打开网页版使用，无需额外配置环境。

- [ ] 打开官网 getartcraft.com/apps/vectorcraft
- [ ] 按系统下载对应安装包
- [ ] 或直接用浏览器网页版

[查看仓库](https://github.com/storytold/vectorcraft)

**lissy93/dashy**

★26.8k · Vue

给自己搭一个专属导航主页，把常用网站和服务集中在一页管理。

**核心亮点**

- 每个链接可显示实时在线状态
- 内置多种主题和图标可选
- 支持搜索和自定义快捷键
- 可加登录验证，多用户使用

**应用与部署指南**

适合有自己服务器或 NAS 的人，用 Docker 部署最省事；装好后在浏览器打开配置页面编辑即可。

- [ ] 先安装 Docker
- [ ] 按 README 用 Docker 启动 Dashy
- [ ] 浏览器打开配置页面添加链接

[查看仓库](https://github.com/lissy93/dashy)

**google-gemini/gemini-cli**

★108.6k · TypeScript

在命令行里跟 Gemini 对话、让它帮你写代码的 AI 工具。

**核心亮点**

- 在终端里直接向 AI 提问
- 可让 AI 读取和修改项目文件
- 支持接入外部工具扩展能力

**应用与部署指南**

需要先装 Node.js，再全局安装命令行工具；注意现在只面向企业版 Gemini Code Assist 授权用户，个人免费版已迁到另一个工具。

- [ ] 先安装 Node.js
- [ ] 按 README 安装 Gemini CLI
- [ ] 确认自己有企业版 Code Assist 授权

[查看仓库](https://github.com/google-gemini/gemini-cli)

**pytorch/pytorch**

★105.2k · Python

做人工智能和深度学习最常用的 Python 工具库，让电脑算得又快又方便。

**核心亮点**

- 用显卡加速大规模数值计算
- 自动计算模型训练需要的梯度
- 可和 NumPy 等常用库配合使用

**应用与部署指南**

需要先装 Python，再按官网给出的命令安装；有 NVIDIA 显卡的还要装对应 CUDA 版本，新手建议照官网选择器一步步来。

- [ ] 先安装 Python
- [ ] 按官网安装命令安装 PyTorch
- [ ] 有显卡则选对应 CUDA 版本

[查看仓库](https://github.com/pytorch/pytorch)
