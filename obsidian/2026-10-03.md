# GitHub 热门效率与 AI 工具

*让 AI 帮你改游戏、做决策、管文件、连流程、跑模型。*

**rehan-remade/universal-modder**

★2.1k · Python · 近期趋势

让 AI 助手帮你给自己电脑上的游戏做模组，从找代码到做素材全包。

**核心亮点**

- 自动识别游戏引擎和改法路线
- 用 AI 生成美术、3D 和音效素材
- 在运行中的游戏里测试模组效果
- 把经验记下来供下次复用

**应用与部署指南**

需要先装好 Claude Code、Codex 等 AI 编程助手，再按对应方式安装插件；装完在游戏目录里启动助手即可。

- [ ] 先安装 Claude Code 或其他支持的 AI 助手
- [ ] 在 Claude Code 里执行 /plugin marketplace add rehan-remade/universal-modder
- [ ] 再执行 /plugin install universal-modder@universal-modder
- [ ] 在游戏目录中启动助手开始改模组

```bash
/plugin marketplace add rehan-remade/universal-modder
```

[查看仓库](https://github.com/rehan-remade/universal-modder)

**mizorewww/laya-mlx**

★6.7k · Python · 近期趋势

在苹果电脑上本地跑的小模型，专门做分类判断，不用联网也不生成文字。

**核心亮点**

- 本地运行，不上传数据到云端
- 短判断只要十几毫秒
- 不生成文字，只输出选项结果
- 支持多语言版本

**应用与部署指南**

需要苹果芯片的 Mac、Python 3.11 以上和 macOS 14 以上；用 pip 装好后写几行代码调用，首次运行会自动下载模型。

- [ ] 确认是 Apple Silicon 且 macOS 14+
- [ ] 安装 Python 3.11 或更高版本
- [ ] 执行 pip install laya-mlx
- [ ] 在代码里 load 模型并调用 predict

```bash
pip install laya-mlx
```

[查看仓库](https://github.com/mizorewww/laya-mlx)

**jarun/nnn**

★22k · C

一个在终端里用的文件管理器，体积小、启动快，适合键盘操作。

**核心亮点**

- 在命令行里浏览和管理文件
- 分析磁盘占用情况
- 批量重命名文件
- 用插件扩展预览、挂载等功能

**应用与部署指南**

在 Linux、macOS、安卓 Termux 等系统的终端里安装即可使用，无需图形界面，几乎不用配置。

- [ ] 打开终端
- [ ] 按系统包管理器安装 nnn
- [ ] 输入 nnn 启动文件管理器

[查看仓库](https://github.com/jarun/nnn)

**n8n-io/n8n**

★206.5k · TypeScript

把各种软件连起来自动干活的工具，还能搭 AI 流程，可自己部署。

**核心亮点**

- 拖拽画布搭自动化流程
- 连接 1500 多个第三方服务
- 可接入多种 AI 模型不锁定厂商
- 能自己写代码扩展流程

**应用与部署指南**

需要先装 Docker；用官方脚本或 Docker 命令启动后，浏览器打开本地 5678 端口就能用。

- [ ] 先安装 Docker
- [ ] 执行 curl -fsSL https://get.n8n.io | sh
- [ ] 浏览器访问 http://localhost:5678

```bash
curl -fsSL https://get.n8n.io | sh
```

[查看仓库](https://github.com/n8n-io/n8n)

**tensorflow/tensorflow**

★200.7k · C++

谷歌开源的机器学习工具，用来训练和运行 AI 模型。

**核心亮点**

- 搭建和训练神经网络模型
- 支持 Python 和 C++ 调用
- 可用 GPU 加速计算
- 提供大量现成工具和库

**应用与部署指南**

需要先装 Python，用 pip 安装即可；想用显卡加速要额外配置 CUDA，也可以用 Docker 镜像。

- [ ] 安装 Python 环境
- [ ] 执行 pip install tensorflow
- [ ] 在代码中 import tensorflow 开始使用

```bash
pip install tensorflow
```

[查看仓库](https://github.com/tensorflow/tensorflow)
