**ccch1mneyyy/dsh-Go**

★2.4k · Dart · 近期趋势

把 AI 编程助手装进安卓手机，本机跑也能遥控电脑。

**核心亮点**

- 手机内置 Linux 环境，免 Root 直接跑
- 一键切换电脑上的助手接着用
- 回复中途可插话，过程自动折叠
- 对话生成加密链接，浏览器回放

**应用与部署指南**

从 GitHub Releases 或官网下载 APK 安装，常见手机选 arm64 包；装过旧测试包需先卸载。

- [ ] 从 GitHub Releases 或官网下载最新 APK
- [ ] 常见手机选择 arm64 安装包
- [ ] 装过旧测试包需先卸载再安装
- [ ] 打开 App 按使用指南配置模型

[查看仓库](https://github.com/ccch1mneyyy/dsh-Go)

**rehan-remade/universal-modder**

★9.2k · Python · 近期趋势

让 AI 助手帮你给电脑游戏做模组，从找代码到生成素材。

**核心亮点**

- 自动识别游戏引擎和改造路线
- 用 AI 生成美术、3D 和音效素材
- 在运行中的游戏里测试模组
- 把经验写下来供下次复用

**应用与部署指南**

需先有 Claude Code、Codex 等 AI 编程助手，再按对应命令安装插件；部分素材生成依赖 fal 服务。

- [ ] 先安装 Claude Code 等 AI 编程助手
- [ ] 在 Claude Code 执行 /plugin marketplace add rehan-remade/universal-modder
- [ ] 再执行 /plugin install universal-modder@universal-modder
- [ ] 按提示配置 fal 素材生成服务

```bash
/plugin marketplace add rehan-remade/universal-modder
```

[查看仓库](https://github.com/rehan-remade/universal-modder)
