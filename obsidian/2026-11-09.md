# GitHub 热门效率与 AI 工具

*从画架构图到本地跑 AI，这批工具帮普通人把 AI 用顺手。*

**caru-ini/stack-diagram**

★2.1k · TypeScript · 近期趋势

用一句话描述你的技术架构，自动生成带官方图标的架构图，省去手动画图的麻烦。

**核心亮点**

- 一句话生成架构图
- 自动配上官方品牌图标
- 支持深浅色两种主题
- 覆盖云服务与开发工具

**应用与部署指南**

这是给 AI 助手用的技能包，需在 Claude Code、Codex、Cursor 等支持技能的工具里安装；Claude 应用里则上传 Releases 中的 zip 包。

- [ ] 准备支持技能功能的 AI 助手（如 Claude Code）
- [ ] 运行 npx skills add caru-ini/stack-diagram
- [ ] 在对话里描述你的技术栈即可出图

```bash
npx skills add caru-ini/stack-diagram
```

[查看仓库](https://github.com/caru-ini/stack-diagram)

**kingcharleslzy-ai/dsh-purge**

★5.4k · JavaScript · 近期趋势

给 DeepSeek Harness 用的本机插件，减少 AI 反复确认打断，让任务能连续跑完。

**核心亮点**

- 一屏看清安装与补丁状态
- 操作前自动快照可回滚
- 集中管理提示词与预设
- 改坏了能一键撤回

**应用与部署指南**

装在自己电脑上，需先有 DSH Desktop 0.2.2-rc.1 等对应版本；从 Releases 下载安装器运行，安装前建议先做 dry-run 自查。

- [ ] 先安装 DSH Desktop 对应版本
- [ ] 从 Releases 下载安装脚本
- [ ] 先跑 dry-run 自查环境
- [ ] 确认无误后正式安装

[查看仓库](https://github.com/kingcharleslzy-ai/dsh-purge)

**rowboatlabs/rowboat**

★18.1k · TypeScript

开源的私人 AI 助理，自带邮件、笔记和白板，能记住你的工作内容并帮你干活。

**核心亮点**

- 把邮件会议整理成知识图谱
- 自动为重要邮件起草回复
- 定时或按事件触发后台任务
- 内置隔离浏览器供协作

**应用与部署指南**

直接下载 Mac/Windows/Linux 安装包即可使用，无需自己配环境；想接哪些账号由你决定。

- [ ] 访问项目下载页
- [ ] 下载对应系统的安装包
- [ ] 安装后登录并接入工作账号

[查看仓库](https://github.com/rowboatlabs/rowboat)
