**Gathin23/cleanyourtv**

★5.2k · Java · 近期趋势

给安卓电视去广告、换清爽首页，不用拆机不用刷机

**核心亮点**

- 无线连接电视，关掉厂商预装的广告和多余服务
- 装一个轻量新桌面，首页像苹果电视一样干净
- 不卸载任何东西，后悔了可一键恢复原样

**应用与部署指南**

需要一台安卓或谷歌电视和电脑，在电视开发者选项里打开 USB 调试并允许电脑连接，然后按 README 用安卓调试工具操作。

- [ ] 在电视开发者选项里打开 USB 调试
- [ ] 在电视上允许电脑连接一次
- [ ] 按 README 备份已安装应用列表
- [ ] 用 pm disable-user 关闭广告与预装服务
- [ ] 安装小桌面并设为默认首页

[查看仓库](https://github.com/Gathin23/cleanyourtv)

**storytold/photocraft**

★68.5k · Rust · 近期趋势

一个开源修图软件，操作像 Photoshop，能直接打开和保存 PSD 文件

**核心亮点**

- 支持图层、蒙版、调整图层和文字排版
- 能打开、编辑并保存带图层的 PSD 文件
- 本地离线运行，快捷键和面板沿用 Photoshop 习惯

**应用与部署指南**

这是装在电脑上的本地应用，README 有下载章节，可从官网或发布页获取安装包；无需联网，也不依赖浏览器。

- [ ] 打开 README 的 Downloads 章节
- [ ] 下载对应系统的安装包
- [ ] 安装后打开即可开始修图

[查看仓库](https://github.com/storytold/photocraft)
