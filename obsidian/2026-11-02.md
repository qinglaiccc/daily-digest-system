**patch-gg/pixelfx**

★2.5k · JavaScript · 近期趋势

244 个像素风特效小动画，做游戏或网页时直接拿来用，不用自己画。

**核心亮点**

- 火焰、爆炸、魔法、天气等特效现成可用
- 可实时播放、改颜色、左右镜像
- 能导出精灵图给任意游戏引擎使用
- 附带 AI 技能，帮你按需生成新特效

**应用与部署指南**

打开在线画廊就能预览和调色；想自己生成新特效，需在 Claude Code 等 AI 编程工具里加载它附带的技能。

- [ ] 打开在线画廊 https://patch-gg.github.io/pixelfx/ 预览特效
- [ ] 挑选特效并调整颜色、镜像方向
- [ ] 导出精灵图，放进自己的游戏或网页

[查看仓库](https://github.com/patch-gg/pixelfx)

**ly05010419/MacNativeGames**

★6.8k · C · 近期趋势

让正版《塞尔达传说》在苹果电脑和 iPhone 上原生运行的技术实验项目。

**核心亮点**

- 在苹果芯片设备上直接运行游戏代码
- 支持 Mac、iPhone 和 iPad
- 不是模拟器，不附带任何游戏内容

**应用与部署指南**

必须自己拥有游戏，并从自己的 Switch 导出游戏文件和密钥，再在电脑上编译出 App；项目本身不含游戏内容，不能直接下载来玩。

- [ ] 确认自己拥有正版游戏和 Switch 主机
- [ ] 从自己的 Switch 导出游戏文件与密钥
- [ ] 按仓库说明在电脑上编译出 App
- [ ] 编译产物仅限自用，不要分享

[查看仓库](https://github.com/ly05010419/MacNativeGames)

**danielmiessler/LifeOS**

★19.7k · TypeScript

一套让 AI 记住你是谁、想做什么，再帮你把生活和工作推向理想状态的方法。

**核心亮点**

- 记录你的身份、关注点和目标
- 让 AI 带着你的完整背景来帮忙
- 覆盖写代码、创业、创作等各类事情

**应用与部署指南**

不需要自己敲命令：把安装提示词粘进 Claude Code、Cursor 等 AI 编程工具，它会读安装页并一步步帮你装好，动手前会先征求同意。

- [ ] 准备一个可用的 AI 编程工具，如 Claude Code
- [ ] 粘贴提示词：Read https://ourlifeos.ai/install and install LifeOS for me.
- [ ] 按 AI 的引导逐步确认完成设置

```bash
curl -fsSL https://ourlifeos.ai/install.sh | bash
```

[查看仓库](https://github.com/danielmiessler/LifeOS)

- [ ] 准备一台服务器或云主机

- [ ] 用 hermes model 选择要用的 AI 模型
- [ ] 接入 Telegram 等聊天平台开始使用

[查看仓库](https://github.com/NousResearch/hermes-agent)

**n8n-io/n8n**

★209.3k · TypeScript

拖拖拽拽就能把各种软件连起来自动干活，还能接入 AI 的工作流工具。

**核心亮点**

- 可视化画布搭建自动化流程
- 连接 1500 多个外部服务
- 可接入 OpenAI、Anthropic 等模型
- 需要时能插入 JavaScript、Python 代码

**应用与部署指南**

需要先装 Docker，用一条安装脚本或 Docker 命令在本地跑起来，然后在浏览器打开 localhost:5678 使用；也可以直接用官方云版。

- [ ] 先安装 Docker
- [ ] 执行 curl -fsSL https://get.n8n.io | sh
- [ ] 浏览器访问 http://localhost:5678 打开编辑器

```bash
curl -fsSL https://get.n8n.io | sh
```

[查看仓库](https://github.com/n8n-io/n8n)
