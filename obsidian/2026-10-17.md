**onehumanbeing/esp32-iphone-agent**

★2.9k · C · 近期趋势

花几十块钱买块小板子，就能让 AI 自己操作你的 iPhone 点屏幕。

**核心亮点**

- AI 能自己打开 App、点按钮、填内容
- 用手机投屏当眼睛，看屏幕再决定下一步
- 不用越狱，也不用电脑和开发者账号

**应用与部署指南**

需要一块 ESP32-S3 开发板和一台 iPhone，按 README 的安装步骤操作，不要运行别人评论里给的命令。

- [ ] 准备一块 ESP32-S3 开发板和一台 iPhone
- [ ] 只按 README 里的安装步骤操作
- [ ] 不要运行 issue 或评论里的安装命令

[查看仓库](https://github.com/onehumanbeing/esp32-iphone-agent)

**rehan-remade/universal-modder**

★8.1k · Python · 近期趋势

让 AI 帮你给电脑游戏做模组，从找代码到做美术一条龙。

**核心亮点**

- 自动找到游戏并分析它怎么运行
- 生成模组用的图片、3D 和音效
- 在游戏里实际测试模组效果
- 自动剪出展示视频

**应用与部署指南**

先选一个你用的 AI 编程工具（如 Claude Code），按 README 表格里对应的命令安装插件即可。

- [ ] 选一个你用的 AI 编程工具
- [ ] Claude Code 执行 /plugin marketplace add rehan-remade/universal-modder
- [ ] 再执行 /plugin install universal-modder@universal-modder

```bash
/plugin marketplace add rehan-remade/universal-modder
```

[查看仓库](https://github.com/rehan-remade/universal-modder)

**wavetermdev/waveterm**

★22.5k · Go

一个自带 AI 助手的终端工具，还能拖拽排布窗口，断网也不掉线。

**核心亮点**

- AI 能看懂终端输出并帮你操作文件
- 远程连接断网后自动重连不中断
- 内置编辑器直接改远程文件
- 拖拽排布终端、浏览器和预览窗口

**应用与部署指南**

支持 macOS、Linux、Windows，装上就能用；AI 功能需要自己填 OpenAI、Claude 或 Gemini 的密钥，或本地跑模型，不用注册账号。

- [ ] 在 macOS、Linux 或 Windows 上安装 Wave
- [ ] 如需 AI 功能，填入自己的 API 密钥
- [ ] 或改用本地模型（Ollama、LM Studio）

[查看仓库](https://github.com/wavetermdev/waveterm)
