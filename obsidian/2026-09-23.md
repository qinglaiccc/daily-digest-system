**mizorewww/laya-coreml**

★1.3k · Python · 近期趋势

在苹果电脑上本地跑小型决策 AI，不用联网、不生成文字，几毫秒出结果。

**核心亮点**

- 本地运行，断网也能用
- 一次判断约 5 毫秒，反应很快
- 自带贪吃蛇演示，能看概率和延迟
- 比同类方案更省电

**应用与部署指南**

需要苹果 M 系列芯片的 Mac、macOS 15 以上、Python 3.11 到 3.13。用 pip 装好后下载模型，再运行贪吃蛇演示即可，首次启动可能要等几十秒。

- [ ] 确认是苹果 M 芯片 Mac 且系统为 macOS 15+
- [ ] 安装 Python 3.11 到 3.13
- [ ] pip install 'laya-coreml[demo]'
- [ ] hf download aac6fef/laya-multilingual-coreml-ane --local-dir models/snake
- [ ] laya-coreml-snake --model ./models/snake

[查看仓库](https://github.com/mizorewww/laya-coreml)

**Nanako0129/sepia**

★2.8k · Python · 近期趋势

帮 AI 写的东西去掉那股机器味，让文章和小说读起来更像人写的。

**核心亮点**

- 改写文字，去掉 AI 腔
- 只诊断不改动，先看问题在哪
- 小说会先修故事结构再改词句
- 不同文体用不同规则

**应用与部署指南**

这是一个给 AI 助手用的技能包，支持 77 种以上助手。用 Skills CLI 一条命令安装，Claude Code、Codex 等还有专门插件版本。

- [ ] 确认你的 AI 助手支持 Agent Skills 标准
- [ ] 用 Skills CLI 安装该技能
- [ ] 在助手对话中调用 write 或 review 等操作

[查看仓库](https://github.com/Nanako0129/sepia)

**feder-cr/invisible_playwright_mcp**

★31.6k · Python

一个不容易被网站识别的浏览器助手，你用大白话说要干什么，它自己上网操作。

**核心亮点**

- 用大白话指挥它上网操作
- 不容易被网站拦截或弹验证码
- 能接进 Claude Code 等编程助手
- 自带网页界面，左边聊天右边看浏览器

**应用与部署指南**

先装 uv 工具，再把它装进你的 AI 助手；或者用网页版，需要自备 OpenRouter 的 API Key，然后打开本地网页使用。

- [ ] 安装 uv 工具
- [ ] claude plugin marketplace add feder-cr/invisible_playwright_mcp
- [ ] claude plugin install aihawk@feder-cr
- [ ] 或运行 uvx aihawk ui --openrouter-key sk-or-...
- [ ] 打开 http://127.0.0.1:8765 开始使用

```bash
uvx aihawk ui --openrouter-key sk-or-...
```

[查看仓库](https://github.com/feder-cr/invisible_playwright_mcp)
