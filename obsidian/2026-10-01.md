# GitHub 热门效率与 AI 工具

**feder-cr/dots**

★1.9k · Python · 近期趋势

给 AI 配一个自带浏览器，让它上网操作时不容易被网站拦下来。

**核心亮点**

- AI 自己开浏览器上网操作
- 换模型只需改一个参数
- 每次运行保持同一身份
- 鼠标键盘动作像真人

**应用与部署指南**

需要先装 uv 工具，然后一条命令启动，浏览器打开本地地址就能用；要自备 OpenRouter 的 API Key。

- [ ] 安装 uv 工具（README 提供一键脚本）
- [ ] 运行 uvx 命令启动 dots
- [ ] 带上自己的 OpenRouter Key
- [ ] 打开 http://127.0.0.1:8765 使用

```bash
uvx --from git+https://github.com/feder-cr/dots dots --openrouter-key sk-or-...
```

[查看仓库](https://github.com/feder-cr/dots)

**wavetermdev/waveterm**

★22.4k · Go

一个带 AI 助手的终端工具，把命令行、文件编辑和网页浏览放在同一个窗口里。

**核心亮点**

- AI 助手能看懂终端输出
- 远程连接断网后自动重连
- 内置编辑器改远程文件
- 拖拽排列终端和网页块

**应用与部署指南**

支持 macOS、Linux、Windows，从官网下载安装包即可；用 AI 功能需自备 OpenAI、Claude 等 API Key，也可接本地模型。

- [ ] 访问官网下载对应系统安装包
- [ ] 安装后打开 Wave 终端
- [ ] 按需填入自己的 AI API Key

[查看仓库](https://github.com/wavetermdev/waveterm)

**espanso/espanso**

★391k · TypeScript

装在自己电脑上的 AI 助手，能在你常用的聊天软件里直接对话干活。

**核心亮点**

- [ ] 在聊天软件里开始对话

```bash

```
