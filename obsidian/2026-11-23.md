# GitHub 热门效率与 AI 工具

*让 AI 帮你提速代码、查代码、跑游戏、管文件、搭智能应用*

**EL4CTEO/fast-anything**

★1.9k · Rust · 近期趋势

不用重写整个程序，只把最慢的几段函数换成更快的版本，并验证结果一致。

**核心亮点**

- 自动找出程序里最耗时的函数
- 让 AI 编程助手只改写这几个函数
- 用真实调用记录验证改写前后结果相同
- 一条命令切换新旧版本，可随时还原

**应用与部署指南**

需要先装好 Node 和 Rust 工具链，然后用 npm 全局安装，在项目目录里运行命令即可。

- [ ] 先安装 Node 和 Rust 工具链（rustup）
- [ ] npm i -g @el4cteo/fast-anything
- [ ] fast-anything go --agent claude -- python app.py

[查看仓库](https://github.com/EL4CTEO/fast-anything)

**valentderah/totk-pc-recomp**

★8k · C · 近期趋势

把《塞尔达传说：王国之泪》转成能在 Windows 和 Linux 电脑上直接运行的程序。

**核心亮点**

- 在电脑上原生运行，不是模拟器
- 默认 60 帧，可调更高帧率
- 支持自定义分辨率和高清放大
- 支持 NSP、XCI 等游戏文件格式

**应用与部署指南**

需要你自己从主机导出合法拥有的游戏文件和更新包，项目不提供游戏文件；在电脑上构建后运行，目前仍是早期版本，可能有画面问题和崩溃。

- [ ] 准备自己导出的游戏本体和更新文件
- [ ] 按文档在 Windows 或 Linux 上构建
- [ ] 运行构建出的程序开始游戏

[查看仓库](https://github.com/valentderah/totk-pc-recomp)

**jarun/nnn**

★22.1k · C

一个在终端里用的文件管理器，体积小、启动快，用键盘就能管文件。

**核心亮点**

- 在终端里浏览和管理文件
- 分析磁盘占用、批量重命名
- 可装插件实现预览、挂载磁盘等
- 体积约 150KB，几乎不用配置

**应用与部署指南**

需要在 Linux、macOS 或 WSL 等终端环境里使用，按 README 的安装说明装好后在终端输入 nnn 启动。

- [ ] 准备 Linux、macOS 或 WSL 终端环境
- [ ] 按 README 安装说明安装 nnn
- [ ] 在终端输入 nnn 启动

[查看仓库](https://github.com/jarun/nnn)

**langchain-ai/langchain**

★150k · Python

帮开发者把大模型和各种工具拼起来，做出能对话、能办事的 AI 应用。

**核心亮点**

- 把大模型和外部工具连接起来
- 提供现成的第三方服务集成
- 配套工具可调试和部署 AI 应用

**应用与部署指南**

需要会 Python，用 uv 安装后写几行代码调用模型；使用前要准备好对应模型服务的账号或密钥。

- [ ] 先安装 Python 和 uv 包管理工具
- [ ] uv add langchain
- [ ] 准备好模型服务的 API Key 后写代码调用

[查看仓库](https://github.com/langchain-ai/langchain)

**Graphify-Labs/graphify**

★152k · Python

把整个代码库连同文档、表格变成一张可查询的关系图，帮 AI 助手读懂项目。

**核心亮点**

- 在 AI 编程助手里输入 /graphify 生成项目地图
- 代码在本地解析，不上传
- 每条关联都标明是直接读到还是推断的
- 支持代码、文档、PDF、图片和视频

**应用与部署指南**

在 Claude Code、Cursor、Codex 或 Gemini CLI 等 AI 编程助手里输入 /graphify 即可；也可访问官网免费开始使用。

- [ ] 打开支持技能的 AI 编程助手
- [ ] 在对话里输入 /graphify
- [ ] 或访问官网免费注册使用

[查看仓库](https://github.com/Graphify-Labs/graphify)
