**Verlintas/NOIR**

★2.5k · Kotlin · 近期趋势

在电脑上检查安卓手机里哪些应用在偷看数据、往哪发，并给出可撤销的处理建议。

**核心亮点**

- 列出有网络和敏感权限的应用
- 从安装包里提取上报网址
- 按厂商和用途给风险打分
- 给出可回滚的处置命令

**应用与部署指南**

在电脑上运行，需要先装好 adb 并打开手机的 USB 调试；首次运行会进入向导，自动检查环境、等你插线，再问几个 y/n 就出报告。

- [ ] 安装 adb 并打开手机开发者模式与 USB 调试
- [ ] 运行 noir 进入向导
- [ ] 按提示插线并确认开始扫描
- [ ] 查看报告后决定是否执行处置

```bash
noir
```

[查看仓库](https://github.com/Verlintas/NOIR)

**huggingface/transformers**

★168.6k · Python

AI 模型的通用工具箱，让开发者用同一套写法调用上百万个文本、图像、语音模型。

**核心亮点**

- 一套代码调用上百万个预训练模型
- 覆盖文字、图像、音频和多模态

- [ ] 用 venv 或 uv 创建并激活虚拟环境
- [ ] 在环境中安装 transformers 库
