# GitHub 热门效率与 AI 工具

**storytold/photocraft**

★2k · Rust · 近期趋势

一个开源免费的修图软件，界面和快捷键都照着 Photoshop 来，不用联网也能用。

**核心亮点**

- 支持图层、蒙版、调整图层等修图功能
- 能打开、编辑并保存真正的 PSD 文件
- 菜单和快捷键与 Photoshop 一致，上手快
- 本地运行，不联网，作品留在自己电脑上

**应用与部署指南**

这是装在电脑上的原生软件，不是网页版。README 里没有给出安装命令，具体下载和安装方式需要到官网 getartcraft.com 查看。

- [ ] 前往官网 getartcraft.com 查看下载方式
- [ ] 下载对应系统的安装包并安装
- [ ] 打开软件即可开始修图

[查看仓库](https://github.com/storytold/photocraft)

**alyssaxuu/screenity**

★18.8k · JavaScript

一个免费、不限时长的录屏工具，装在浏览器里，录完还能直接在屏幕上画标注。

**核心亮点**

- 不限时长录制屏幕、标签页、摄像头
- 可录麦克风或电脑内部声音
- 录制时能在画面上画箭头、加文字
- 支持 AI 摄像头背景虚化或替换

**应用与部署指南**

它是一款浏览器扩展，装好后在浏览器里点开就能录，不用装 Node 或 Docker。README 里没有给出安装命令，需从浏览器扩展商店或官网获取。

- [ ] 从浏览器扩展商店或官网安装 Screenity
- [ ] 在浏览器中打开扩展并选择录制范围
- [ ] 开始录制，录完可直接编辑导出

[查看仓库](https://github.com/alyssaxuu/screenity)

**mrkai77/Loop**

★11.7k · Swift

一款让 Mac 窗口摆放变简单的工具，按住一个键拖动鼠标就能移动和调整窗口大小。

**核心亮点**

- 按住触发键拖动鼠标即可调整窗口
- 调整前可先预览窗口最终位置
- 可自定义快捷键和配色主题
- 把窗口藏到屏幕边缘，随时唤出

**应用与部署指南**

这是 macOS 应用，需要 macOS 13 或更高版本。README 里没有给出安装命令，需从项目页面下载安装包。

- [ ] 确认电脑系统为 macOS 13 或更高版本
- [ ] 从项目页面下载 Loop 安装包
- [ ] 安装后打开，按住触发键拖动鼠标调整窗口

[查看仓库](https://github.com/mrkai77/Loop)

**huggingface/transformers**

★167k · Python

一个让开发者方便调用各种 AI 模型的工具库，文字、图片、语音模型都能用同一套方式加载。

**核心亮点**

- 用统一方式加载文字、图像、语音等模型
- 可在线获取上百万个现成模型
- 既能用来跑模型，也能用来训练模型
- 兼容多种主流训练和推理工具

**应用与部署指南**

需要先装 Python 3.10 以上和 PyTorch 2.5 以上，建议用虚拟环境。README 给出的第一步是创建虚拟环境，之后用 pip 安装。

- [ ] 先安装 Python 3.10+ 和 PyTorch 2.5+
- [ ] python -m venv .my-env
- [ ] 激活虚拟环境后安装 transformers

[查看仓库](https://github.com/huggingface/transformers)
