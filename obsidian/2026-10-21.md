# GitHub 热门效率与 AI 工具

*从做游戏、画3D模型到录屏和用AI，这批工具帮你把创意落地。*

**ahwootech/BRUTAL**

★2.1k · C# · 近期趋势

一个免费开源的C#游戏开发框架，让你能自己动手做游戏或搭游戏引擎。

**核心亮点**

- 直接用C#写游戏，也能当自研引擎的地基
- 自带数学、内存、任务调度等基础零件
- 接好了图形、物理、音频等底层库
- 不替你做架构决定，可自由搭配第三方包

**应用与部署指南**

面向有C#基础的开发者，需要先装好.NET开发环境，再按官网文档把框架引入自己的项目。上手比Unity等商业引擎更费劲，适合想完全掌控工具链的人。

- [ ] 先安装 .NET 开发环境
- [ ] 访问官网 ahwoo.com/brutal 查看文档
- [ ] 按文档把 BRUTAL 引入你的 C# 项目

[查看仓库](https://github.com/ahwootech/BRUTAL)

**tangency-labs/solidcraft**

★8.3k · Rust · 近期趋势

一个开源的3D建模软件，画草图、改尺寸，模型会自动跟着重建。

**核心亮点**

- 画草图加约束，搭出立体零件
- 改一个尺寸，整个模型自动重算
- 桌面、浏览器都能用，无需安装
- 内置接口让AI助手也能建模

**应用与部署指南**

普通用户直接下载安装包，或用浏览器打开网页版即可；Windows也可用winget安装，Linux可用snap。下载包暂未签名，Windows需点“更多信息→仍要运行”。

- [ ] Windows 执行 winget install bherbruck.SolidCraft
- [ ] macOS 下载磁盘映像后右键选“打开”
- [ ] Linux 执行 sudo snap install solidcraft
- [ ] 或直接打开网页版试用，无需安装

```bash
winget install bherbruck.SolidCraft
```

[查看仓库](https://github.com/tangency-labs/solidcraft)

**alyssaxuu/screenity**

★18.8k · JavaScript

一个免费、注重隐私的录屏工具，能录屏幕、摄像头并直接在画面上做标注。

**核心亮点**

- 不限时长录制标签页、区域或整个桌面
- 录麦克风或电脑内部声音
- 在画面上画图、加文字箭头和形状
- 用AI给摄像头画面换背景或虚化

**应用与部署指南**

它是一款浏览器扩展，在Chrome应用商店安装后点开就能录，不用装额外软件。想自己部署或改代码，README另有自建和开发版说明。

- [ ] 在 Chrome 应用商店安装 Screenity 扩展
- [ ] 点开扩展选择录制范围
- [ ] 录完在扩展内直接标注和导出

[查看仓库](https://github.com/alyssaxuu/screenity)

**f/prompts.chat**

★173.7k · HTML

一个超大的开源AI提示词库，帮你找到好用的提问模板，也能自己部署。

**核心亮点**

- 浏览社区分享的海量提示词
- 兼容ChatGPT、Claude、Gemini等模型
- 提供免费互动教程学写提示词
- 支持组织自建，数据完全私有

**应用与部署指南**

普通用户直接访问 prompts.chat 网页浏览即可；想让团队内部私有使用，可按README的Self-Host章节自行部署。

- [ ] 访问 prompts.chat 浏览提示词
- [ ] 需要私有部署时查看 Self-Host 章节

[查看仓库](https://github.com/f/prompts.chat)

**huggingface/transformers**

★167.9k · Python

一个让开发者方便调用各种AI模型的Python工具库，文本、图片、语音都能用。

**核心亮点**

- 一个库调用上百万个预训练模型
- 覆盖文字、图像、音频和多模态
- 既能拿来推理，也能用来训练
- 兼容主流训练和推理框架

**应用与部署指南**

需要先装Python 3.10以上和PyTorch 2.6以上，建议用虚拟环境隔离依赖，再用pip安装。适合有Python基础的开发者。

- [ ] 安装 Python 3.10+ 和 PyTorch 2.6+
- [ ] 创建并激活虚拟环境
- [ ] 执行 pip install transformers

```bash
pip install transformers
```

[查看仓库](https://github.com/huggingface/transformers)
