# GitHub 热门效率与 AI 工具

*让 AI 更会做判断、守规矩、干活和自动操作网页*

**NandhaKishorM/laya**

★20.4k · Python · 近期趋势

给一段文字快速做选择题、打分或判断是/否的 AI 小工具，不用等它慢慢写字。

**核心亮点**

- 一次就能给出答案，不用逐字生成
- 支持 100 多种语言的文字判断
- 能自动挑合适的模型处理请求

**应用与部署指南**

面向开发者，需要 Python 环境，从 Hugging Face 下载模型后调用；普通用户暂时用不上。

- [ ] 准备 Python 环境
- [ ] 从 Hugging Face 下载 laya 模型
- [ ] 调用模型对文字做判断

[查看仓库](https://github.com/NandhaKishorM/laya)

**shadcn-ui/lint**

★2.7k · TypeScript · 近期趋势

给 AI 写代码时立规矩的检查工具，防止它乱改你的界面样式。

**核心亮点**

- 自定义设计规则，AI 违规就报错
- 报错时告诉 AI 该怎么改
- 支持 React、Svelte、Vue 项目

**应用与部署指南**

需要 Node 环境，在 Tailwind v4 项目里安装；也可以把 SETUP.md 链接丢给 AI 助手自动配置。

- [ ] 准备 Node 环境
- [ ] 把 SETUP.md 链接发给 AI 助手配置
- [ ] 选择并配置你的设计规则

[查看仓库](https://github.com/shadcn-ui/lint)

**rowboatlabs/rowboat**

★18k · TypeScript

装在电脑上的开源 AI 助手，帮你管邮件、记笔记、开会记录还能自动干活。

**核心亮点**

- 把邮件、会议、聊天整理成知识库
- 自动给重要邮件起草回复
- 可设定时或触发式后台任务

**应用与部署指南**

直接下载 Mac/Windows/Linux 安装包即可使用，无需自己搭环境。

- [ ] 从官网下载对应系统安装包
- [ ] 安装并打开 Rowboat
- [ ] 连接邮箱等账号开始使用

[查看仓库](https://github.com/rowboatlabs/rowboat)

**hacksider/Deep-Live-Cam**

★96.8k · Python

用一张照片就能实时换脸，或一键给视频换脸的开源工具。

**核心亮点**

需要 Python 环境，本地运行；使用真人脸需获得对方同意，并标注为换脸内容。

- [ ] 运行程序并选择人脸图片

**puppeteer/puppeteer**

★95.6k · TypeScript

用代码遥控浏览器自动点按钮、填表单、抓网页的工具。

**核心亮点**

- 用代码自动操作浏览器
- 默认后台运行不弹窗口
- 可截图、抓取网页内容

**应用与部署指南**

需要 Node 环境，用 npm 安装；安装时会自动下载配套浏览器，也可手动补下载。

- [ ] 准备 Node 环境
- [ ] 运行 npm i puppeteer
- [ ] 若浏览器未下载，运行 npx puppeteer browsers install

```bash
npm i puppeteer
```

[查看仓库](https://github.com/puppeteer/puppeteer)
