# GitHub 热门效率与 AI 工具

*让 AI 真正动手操作手机、电脑和代码，把助手装进口袋。*

**DIYgod/pinky**

★2.1k · Go · 近期趋势

让 AI 助手直接操作你的 iPhone 或安卓手机，关键步骤由你点头确认。

**核心亮点**

- 电脑上看着 AI 操作手机，危险步骤先问你
- 支持 Claude Code、Cursor 等常见 AI 工具接入
- 也能让手机上的 AI 自己独立完成任务
- 安装包小巧，运行时不怎么占内存

**应用与部署指南**

在 macOS、Windows 或 Linux 电脑上安装 Pinky 客户端，再连接你的手机；iOS 17.4 以下需先用 Mac 上的 Xcode 装一次手机端 App。

- [ ] 从官网或 GitHub 下载对应系统的 Pinky 客户端
- [ ] 在电脑上打开 Pinky 并连接你的手机
- [ ] iOS 17.4 至 26 需先用 Mac 上的 Xcode 安装手机端 App
- [ ] 在电脑上观看 AI 操作并批准风险步骤

[查看仓库](https://github.com/DIYgod/pinky)

**ccch1mneyyy/dsh-Go**

★21.8k · Dart · 近期趋势

把 DeepSeek 编程助手装进安卓手机，手机上直接跑，也能遥控电脑。

**核心亮点**

- 手机本地运行，不用 Root 也不用装 Termux
- 一键连到电脑上的 DSH 接着干活
- 回复中途能插话，做完的过程自动折叠
- 对话可做成分享卡或加密链接回放

**应用与部署指南**

从 GitHub Releases 或官网下载 APK 安装到安卓手机，常见手机选 arm64 包；首次使用可先看使用指南。

- [ ] 从 GitHub Releases 或官网下载最新版 APK
- [ ] 常见手机选择 arm64 安装包
- [ ] 安装后打开 App，按使用指南配置模型
- [ ] 需要时在 App 内安装 Ubuntu 与 Node.js 环境

[查看仓库](https://github.com/ccch1mneyyy/dsh-Go)

**plotly/dash**

★24.5k · Python

用 Python 写代码就能做出带图表和按钮的网页数据看板，不用学前端。

**核心亮点**

- 下拉框、滑块、图表直接连到 Python 代码
- 支持约 50 种图表类型，包括地图
- 外观可自由调整，能做成报告样式
- 代码写法简单，几十行就能出成品

**应用与部署指南**

需要先装 Python，再安装 Dash 库；写一个 Python 脚本运行后，在浏览器里打开本地地址就能看到看板。

- [ ] 先安装 Python 环境
- [ ] 安装 Dash 库
- [ ] 写一个 Python 脚本并运行
- [ ] 在浏览器打开本地地址查看看板

[查看仓库](https://github.com/plotly/dash)

**morluto/rea**

★457.6k · TypeScript

让 AI 助手帮你拆解别人的软件，看清某个功能到底是怎么做出来的。

**核心亮点**

- 不用源代码也能分析 App 的功能实现
- 能检查手机应用、桌面程序和网页
- 分析在本机完成，结论附带证据和局限
- 也能在终端里直接使用这些分析工具

**应用与部署指南**

需要 Node.js 环境，运行一条命令完成初始化，然后把 REA 接到你常用的 AI 助手里使用。

- [ ] 先安装 Node.js 环境
- [ ] 运行 npx rea-agents setup 完成初始化
- [ ] 把 REA 接入你常用的 AI 助手
- [ ] 让助手分析目标软件并查看证据

```bash
npx rea-agents setup
```

[查看仓库](https://github.com/morluto/rea)

**openclaw/openclaw**

★394.4k · TypeScript

开源的私人 AI 助手，跑在你自己的电脑上，在常用聊天软件里随叫随到。

**核心亮点**

- 在 Discord、微信类聊天工具里直接对话
- 数据、记忆和账号都留在你自己的设备上
- 可换用 Claude、Codex 或本地模型
- 有 macOS、iOS、安卓、Windows 等客户端

**应用与部署指南**

在 macOS、Linux 或 Windows 上运行安装脚本，脚本会自动准备好 Node.js 运行环境，然后按引导配置聊天渠道和模型。

- [ ] macOS/Linux/WSL2 运行 curl -fsSL https://openclaw.ai/install.sh | bash
- [ ] Windows 使用 PowerShell 安装脚本
- [ ] 按引导配置要接入的聊天软件
- [ ] 选择并配置你想用的 AI 模型

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```
