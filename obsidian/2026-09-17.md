# GitHub 热门效率与 AI 工具

*从视频拉片、听歌到做数据看板、跑 AI 模型，这批工具帮你把 AI 用起来。*

**eternityspring/reelbench-skills**

★715 · HTML · 近期趋势

把一条成片拆成逐镜头分析表，还能生成带分镜信息的视频。

**核心亮点**

- 自动拆解视频，列出每个镜头的时长和景别
- 生成可点击跳转的交互式拉片报告
- 把分镜信息叠在画面上，镜头切信息跟着切

**应用与部署指南**

需要先装 Node 18 以上和 ffmpeg，克隆仓库后运行安装脚本，软链到 Claude Code 或 Codex 的 skills 目录即可使用，不需要 API key。

- [ ] 安装 Node 18+ 和 ffmpeg
- [ ] git clone https://github.com/eternityspring/reelbench-skills.git
- [ ] cd reelbench-skills
- [ ] ./scripts/install.sh

[查看仓库](https://github.com/eternityspring/reelbench-skills)

**crmne/spotifast**

★4.3k · Rust · 近期趋势

一个轻量的 Spotify 桌面客户端，听歌更省内存、启动更快。

**核心亮点**

- 内存占用比官方客户端小很多
- 启动不到一秒，没有浏览器引擎
- 可当 Spotify Connect 设备，用手机遥控播放

**应用与部署指南**

支持 Linux、macOS 和 Windows，安装包见官网 spotifast.rocks。播放需要 Spotify Premium 账号，免费账号只能浏览和搜索。

- [ ] 访问 spotifast.rocks 查看安装方式
- [ ] 安装对应系统的客户端
- [ ] 用 Spotify Premium 账号登录

[查看仓库](https://github.com/crmne/spotifast)

**plotly/dash**

★24.4k · Python

用 Python 就能做出带图表和交互的数据网页，不用写 JavaScript。

**核心亮点**

- 下拉框、滑块、图表直接连到 Python 代码
- 支持约 50 种图表类型，包括地图
- 几十行代码就能搭出一个数据应用

**应用与部署指南**

需要先装 Python，然后用 pip 安装 Dash 即可开始写应用，官方教程说五分钟能做出第一个应用。

- [ ] 先安装 Python
- [ ] pip install dash
- [ ] 按官方教程写第一个应用

[查看仓库](https://github.com/plotly/dash)

**huggingface/transformers**

★166.3k · Python

一个统一的模型工具箱，让各种 AI 模型都能用同一套方式调用。

**核心亮点**

- 覆盖文字、图像、音频、视频等多种模型
- 同一套代码可换用不同模型
- 可对接主流训练和推理工具

**应用与部署指南**

需要 Python 3.10 以上和 PyTorch 2.5 以上，建议先建虚拟环境再用 pip 安装，之后就能从模型库下载模型使用。

- [ ] 安装 Python 3.10+ 和 PyTorch 2.5+
- [ ] python -m venv .my-env
- [ ] pip install transformers

[查看仓库](https://github.com/huggingface/transformers)
