# GitHub 热门效率与 AI 工具

*让游戏、电视、时间记录和 AI 数据获取更省心*

**valentderah/totk-pc-recomp**

★4k · C · 近期趋势

把《塞尔达传说：王国之泪》搬到电脑上原生运行，不用模拟器。

**核心亮点**

- 在 Windows 和 Linux 电脑上直接玩
- 默认 60 帧，最高可到 144 帧
- 支持超宽屏和 HDR 画面
- 游戏内按 F1 调设置、F10 看性能

**应用与部署指南**

需要你自己从游戏机里导出正版游戏文件和更新包，项目不提供游戏文件；然后在电脑上编译运行，目前是早期版本，可能有画面问题和崩溃。

- [ ] 准备自己合法获取的游戏本体和更新文件
- [ ] 按 README 说明在电脑上构建项目
- [ ] 运行生成的原生程序开始游戏

[查看仓库](https://github.com/valentderah/totk-pc-recomp)

**Gathin23/cleanyourtv**

★50.4k · Python · 近期趋势

给安卓电视瘦身，去掉预装广告软件，换成苹果电视风格首页。

**核心亮点**

- 通过 Wi-Fi 远程清理电视预装软件
- 把电视首页换成苹果电视风格
- 支持备份和恢复电视设置
- 提供社区做的手机和电脑端应用

**应用与部署指南**

需要一台安卓或谷歌电视，并在电视开发者选项里打开 USB 调试；可以用编程助手约十五分钟完成，或使用社区应用。

- [ ] 在电视开发者选项里打开 USB 调试
- [ ] 允许电脑连接电视一次
- [ ] 按 README 快速开始操作，或使用社区应用

[查看仓库](https://github.com/Gathin23/cleanyourtv)

**ActivityWatch/activitywatch**

★19.5k · Python

自动记录你电脑上用了什么、花了多久，数据只存在自己电脑里。

**核心亮点**

- 记录当前用的软件和窗口标题
- 记录浏览器标签页和网址
- 根据键鼠活动判断你是否离开
- 数据本地保存，自己掌控

**应用与部署指南**

需要先安装 Python 环境，然后从官网下载安装包或按文档安装；数据保存在本地，可自行决定记录多少。

- [ ] 安装 Python 环境
- [ ] 从官网下载对应系统的安装包
- [ ] 安装后启动即可自动记录

[查看仓库](https://github.com/ActivityWatch/activitywatch)

**tensorflow/tensorflow**

★201.3k · C++

谷歌开源的机器学习工具包，帮开发者搭建和训练 AI 模型。

**核心亮点**

- 用 Python 和 C++ 写机器学习程序
- 支持 GPU 加速训练
- 有大量现成工具和社区资源
- 可部署到多种设备和平台

**应用与部署指南**

需要先装 Python，然后用 pip 安装；想用显卡加速要按文档配置 CUDA，也可以改用 Docker 容器。

- [ ] 安装 Python 环境
- [ ] 运行 pip install tensorflow
- [ ] 按文档验证安装是否成功

```bash
pip install tensorflow
```

[查看仓库](https://github.com/tensorflow/tensorflow)

**firecrawl/firecrawl**

★198k · TypeScript

把网页和文档变成 AI 能直接读的干净数据，省去抓取麻烦。

**核心亮点**

- 把任意网页转成 Markdown 或结构化数据
- 支持搜索网页并返回完整内容
- 能解析 PDF、DOCX 等文档
- 可让 AI 在页面上点击滚动后再提取

**应用与部署指南**

可以直接用官方在线服务，也可以自己部署；自部署需要 Node 环境，并可能需要配置 API Key。

- [ ] 访问官网注册获取 API Key
- [ ] 按 README 用一条命令接入 AI 助手
- [ ] 调用接口抓取或搜索网页

[查看仓库](https://github.com/firecrawl/firecrawl)
