# GitHub 热门效率与 AI 工具

*让 AI 更省钱、更聪明，也让电脑操作更顺手。*

**nokia-applied-research/AnyJev**

★827 · Python · 近期趋势

把现成的大模型改造成会给出概率判断的决策助手，不用重新训练。

**核心亮点**

- 让模型对选项给出真实概率，而不是随口猜
- 不用训练，几百条标注就能调好
- 一条命令完成转换、部署和效果测量

**应用与部署指南**

需要 Python 环境，用 pip 安装后按 README 三条命令把模型转成决策接口；适合有技术背景的人本地部署。

- [ ] pip install "anyjev[hf]"
- [ ] python -m anyjev.truncate Qwen/Qwen2.5-7B-Instruct 18 ./qwen-b18
- [ ] vllm serve ./qwen-b18 --task embed

[查看仓库](https://github.com/nokia-applied-research/AnyJev)

**XiaoDuoYa/codex-with-chatgpt**

★6.8k · TypeScript · 近期趋势

让网页版 ChatGPT 负责出主意，Codex 负责动手写代码，省下 API 费用。

**核心亮点**

- 用已付费的网页版 ChatGPT 做规划
- 代码只读不传，仓库不会上传
- 不用 API Key，官方网页加安全桥接

**应用与部署指南**

不懂技术也行：把 README 里那段安装说明原样复制给 Codex，让它自动装好；需要已有 ChatGPT 付费订阅和 Codex。

- [ ] 复制 README 中的安装说明给 Codex
- [ ] 让 Codex 自动完成安装配置
- [ ] 遇到问题先让 Codex 更新到最新版

[查看仓库](https://github.com/XiaoDuoYa/codex-with-chatgpt)

**Wox-launcher/Wox**

★27.5k · Go

一个按快捷键就能搜应用、找文件、执行操作的桌面启动器。

**核心亮点**

- 键盘输入就能打开应用和文件
- 支持插件扩展，可用脚本自己加功能
- 内存占用约 150MB，常驻后台不卡

**应用与部署指南**

Windows、macOS、Linux 都能装，用系统包管理器一条命令即可；装好后按快捷键呼出输入框使用。

- [ ] macOS 执行 brew install --cask wox
- [ ] Windows 执行 winget install -e --id Wox.Wox
- [ ] 安装后按快捷键呼出输入框

```bash
brew install --cask wox
```

[查看仓库](https://github.com/Wox-launcher/Wox)

**rtk-ai/rtk**

★81.8k · Rust

给 AI 编程助手装个过滤器，把命令输出压缩后再喂给模型，省 token 钱。

**核心亮点**

- 压缩命令输出，最多省九成 token
- 支持 100 多种常用命令
- 单个程序文件，不用装依赖

**应用与部署指南**

装一个命令行工具即可，macOS 用 Homebrew、Windows 用 winget、Linux 用脚本；装完让 AI 助手走它转发命令。

- [ ] macOS 执行 brew install rtk
- [ ] Windows 执行 winget install rtk-ai.rtk
- [ ] Linux 执行 curl 安装脚本

```bash
brew install rtk
```

[查看仓库](https://github.com/rtk-ai/rtk)

**netdata/netdata**

★80.7k · Go

实时监控服务器和应用的运行状态，出问题能第一时间看到并报警。

**核心亮点**

- 每秒刷新指标和图表，看得清
- 自动发现异常并发出告警

**应用与部署指南**

README 强调零配置即可部署，通常用官方安装脚本或 Docker 跑起来；具体命令 README 摘录里没给全，建议看官网文档。

- [ ] 参考官网文档选择安装方式
- [ ] 按文档完成部署后打开监控面板
