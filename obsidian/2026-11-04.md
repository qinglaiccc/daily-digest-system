# GitHub 热门效率与 AI 工具

*让 AI 帮你看懂代码、画图建模、写笔记和跑自动化任务*

**haydenschmitty/floorplan**

★2.6k · JavaScript · 近期趋势

让 AI 读完你的代码，画出一张能点开看的中文地图，搞懂程序各部分怎么连起来。

**核心亮点**

- 把每个文件和请求翻译成大白话名字
- 点开地图就能看到各部分之间的连接
- 改完代码后能看出 AI 动了哪些地方
- 地图可随时更新，跟着代码一起变

**应用与部署指南**

需要先装好 Claude Code 或 Codex 这类 AI 编程工具，然后在里面让它生成地图；也可以先打开在线演示网页看看效果，不用安装。

- [ ] 先安装 Claude Code 或 Codex 编程助手
- [ ] 在项目里让 AI 生成 floorplan 地图
- [ ] 打开生成的地图逐块查看和提问

[查看仓库](https://github.com/haydenschmitty/floorplan)

**tangency-labs/solidcraft**

★13.4k · Rust · 近期趋势

一个免费开源的 3D 建模软件，画个草图改个尺寸，模型就自动跟着变。

**核心亮点**

- 画草图加尺寸约束，改数字模型自动重建
- 桌面、浏览器都能用，网页版免安装
- 内置接口让 AI 助手也能帮你建模
- 可导出 STEP 等常见工程格式

**应用与部署指南**

Windows 下 MSI 安装包、macOS 下 DMG 镜像、Linux 下 AppImage 或 Snap 都能装；不想装就直接用浏览器打开网页版。

- [ ] Windows 下载并运行 installer 安装包
- [ ] macOS 下载 disk image 拖入应用
- [ ] Linux 执行 sudo snap install solidcraft
- [ ] 或直接用浏览器打开网页版免安装

```bash
sudo snap install solidcraft
```

[查看仓库](https://github.com/tangency-labs/solidcraft)

**YishenTu/claudian**

★15.9k · TypeScript

给笔记软件 Obsidian 装个 AI 助手，让它直接读写、搜索你笔记库里的文件。

**核心亮点**

- 在笔记里选中文字让 AI 直接改写
- AI 能读写、搜索笔记并执行命令
- 多个会话可组成项目共享记忆
- 输入斜杠或 @ 快速调用模板和文件

**应用与部署指南**

需要先装 Obsidian 笔记软件，再安装这个插件；装好后从侧边栏图标或命令面板打开，接入 Claude Code、Codex 等 AI 工具即可使用。

- [ ] 先安装 Obsidian 笔记软件
- [ ] 在 Obsidian 中安装 Claudian 插件
- [ ] 从侧边栏图标或命令面板打开
- [ ] 接入 Claude Code 或 Codex 等助手

[查看仓库](https://github.com/YishenTu/claudian)

给命令行终端换皮肤、加插件的老牌工具，让敲命令更顺手也更好看。

- [ ] 确认系统已安装 zsh 命令行
- [ ] 运行 README 中的安装脚本命令
- [ ] 重启终端让配置生效

[查看仓库](https://github.com/ohmyzsh/ohmyzsh)

一个 AI 助手团队平台，用大白话派活，由 AI 分工完成写作、销售、调研等任务。
