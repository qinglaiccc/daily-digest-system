**anhao/ai-pose-gallery-zh**

★3.1k · HTML · 近期趋势

一个中文版 AI 绘画姿势参考图库，把日文原站的姿势素材全部翻译并打包，方便找参考图。

**核心亮点**

- 收录 1439 组、2878 张姿势参考图
- 日文分类和姿势名全部翻译成中文
- 可按体系、分类、视角筛选图片
- 支持灯箱浏览和下载原图

**应用与部署指南**

这是一个纯静态网页，打开在线演示就能用；想自己部署的话，把仓库文件放到任意静态网站托管服务上即可，不需要安装任何软件。

- [ ] 访问在线演示站 ai-pose-gallery.anhao.app 直接使用
- [ ] 想自建则下载仓库全部文件
- [ ] 上传到 Cloudflare Pages 等静态托管服务

[查看仓库](https://github.com/anhao/ai-pose-gallery-zh)

**storytold/effectcraft**

★8.2k · Rust · 近期趋势

一个免费开源的动效和视频合成软件，用来做动态标题、动画和视觉特效。

**核心亮点**

- 用图层和关键帧制作动画
- 内置 308 种特效可直接套用
- 支持 3D 摄像机和灯光
- 可导出成品，支持渲染队列

**应用与部署指南**

提供 macOS、Windows、Linux 安装包，也有网页版；去官网下载对应版本安装即可，不需要自己配置开发环境。

- [ ] 打开官网 getartcraft.com/apps/effectcraft
- [ ] 下载对应系统的安装包
- [ ] 安装后打开软件新建合成开始制作

[查看仓库](https://github.com/storytold/effectcraft)

**plotly/dash**

★24.5k · Python

用 Python 写数据看板和交互式网页应用的工具，不用学 JavaScript 也能做出图表页面。

**核心亮点**

- [ ] 先安装 Python 环境
- [ ] 用 pip 安装 Dash 库
- [ ] 按官方教程写第一个应用并运行

[查看仓库](https://github.com/plotly/dash)

**thedotmack/claude-mem**

★104.8k · TypeScript

给 AI 编程助手加一个长期记忆，让它下次接着上次的进度干活，不用每次从头解释。

**核心亮点**

- 自动记录 AI 助手每次会话做了什么
- 用 AI 把记录压缩成摘要保存
- 下次会话自动带上相关背景
- 支持 Claude Code 等多种助手

**应用与部署指南**

需要先有 Node 环境，然后用 npx 命令安装；安装时需指定你用的 AI 助手类型，例如 Grok Bot。

- [ ] 先安装 Node.js 环境
- [ ] 运行 npx claude-mem install --ide grok-bot
- [ ] 按提示完成配置后重启助手

```bash
npx claude-mem install --ide grok-bot
```

[查看仓库](https://github.com/thedotmack/claude-mem)

★97.4k · Python

只要一张照片，就能实时把视频或摄像头里的人脸换成另一张脸。
