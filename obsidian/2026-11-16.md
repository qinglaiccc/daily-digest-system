# GitHub 热门效率与 AI 工具

*让 AI 助手真正参与团队协作、自动化与日常开发，并顺带解决游戏与终端效率问题。*

**agentes-chat/agentes-chat**

★1.5k · TypeScript · 近期趋势

一个可以自己搭建的团队聊天工具，AI 助手像同事一样加入频道一起干活。

**核心亮点**

- AI 助手加入频道和私聊，能读消息并接活
- 敏感操作先等人批准再执行
- 每个 AI 有独立电脑和浏览器可接管
- 支持定时或事件触发的例行任务

**应用与部署指南**

需要一台 Linux 服务器和 Postgres 数据库，用一条命令即可自建；也可直接用官方云端版。

- [ ] 准备一台 Linux 服务器
- [ ] 安装并运行 Postgres 数据库
- [ ] 按 README 用一条命令启动服务
- [ ] 用浏览器或桌面、手机 App 连接你的服务器

[查看仓库](https://github.com/agentes-chat/agentes-chat)

**ly05010419/MacNativeGames**

★7.9k · C · 近期趋势

让苹果芯片的 Mac、iPhone、iPad 直接原生运行你自购的塞尔达游戏，不是模拟器。

**核心亮点**

- 游戏代码直接在苹果芯片上运行
- 支持《王国之泪》《旷野之息》等
- 在 Mac、iPhone、iPad 上玩
- 需自备游戏文件和密钥

**应用与部署指南**

必须自己拥有正版游戏，并从自己的 Switch 导出密钥和系统文件；在电脑上构建出 App 后本地使用，不能分享。

- [ ] 购买正版游戏并准备 Switch 导出文件
- [ ] 从自己的 Switch 导出密钥和系统文件
- [ ] 按 README 在电脑上构建 App
- [ ] 在 Mac 或 iPhone、iPad 上运行自建 App

[查看仓库](https://github.com/ly05010419/MacNativeGames)

**wavetermdev/waveterm**

★22.7k · Go

一个自带 AI 助手的跨平台终端，让命令行操作更顺手、远程连接更稳。

**核心亮点**

- AI 助手能读终端输出并帮忙操作文件
- 远程连接断网后自动重连不丢会话
- 内置编辑器可直接改远程文件
- 拖拽排列终端、浏览器和预览窗口

**应用与部署指南**

支持 macOS、Linux、Windows，装好即可用；AI 功能需自备 OpenAI、Claude 等 API Key，或本地跑模型，无需注册账号。

- [ ] 从官网下载对应系统安装包
- [ ] 安装并打开 Wave Terminal
- [ ] 如需 AI 功能，填入自己的 API Key
- [ ] 或配置 Ollama、LM Studio 使用本地模型

[查看仓库](https://github.com/wavetermdev/waveterm)

- [ ] 按 README 安装 Hermes Agent
- [ ] 用 hermes model 选择要用的模型
- [ ] 接入 Telegram 等聊天工具开始对话

[查看仓库](https://github.com/NousResearch/hermes-agent)

**n8n-io/n8n**

★210.6k · TypeScript

一个可视化搭自动化流程的工具，能把各种软件连起来，还能加入 AI 步骤。

**核心亮点**

- 拖拽画布搭建自动化流程
- 连接 1500 多个现有软件服务
- 可插入 JavaScript、Python 自定义逻辑
- 支持自建部署或使用云端版

- [ ] 或手动执行 docker volume create n8n_data
- [ ] 浏览器访问 http://localhost:5678

curl -fsSL https://get.n8n.io | sh
