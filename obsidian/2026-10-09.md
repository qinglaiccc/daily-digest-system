# GitHub 热门效率与 AI 工具

*让 AI 更好用、让照片和文章更好管的开源工具合集*

**QingYunA/answer-me-with-html**

★2.3k · JavaScript · 近期趋势

让 AI 把复杂问题的答案写成一页排版好的网页，而不是一大段难读的文字。

**核心亮点**

- 提问后自动生成一页可读的 HTML 答案
- 自动画好图表和排版，不用自己动手
- 生成的文件可离线打开，不依赖网络

**应用与部署指南**

这是一个给 AI 助手用的技能插件，装好后照常提问即可。README 未给出具体安装命令，需参考项目官网的安装说明。

- [ ] 打开项目官网查看安装说明
- [ ] 按说明把技能装到你的 AI 助手里
- [ ] 像平时一样提问，等待生成网页

[查看仓库](https://github.com/QingYunA/answer-me-with-html)

**storytold/lightcraft**

★5.5k · Rust · 近期趋势

一个免费开源的修图软件，功能对标 Adobe Lightroom，照片全在自己电脑上处理。

**核心亮点**

- 调光调色，原图不会被改动
- 支持局部蒙版和预设，快速出片
- 可在电脑本地或浏览器里使用

**应用与部署指南**

有 macOS、Windows、Linux 桌面版，也能在浏览器里用。README 未给出具体安装命令，需到官网下载对应版本安装。

- [ ] 打开官网 getartcraft.com 的 LightCraft 页面
- [ ] 下载对应系统的安装包
- [ ] 安装后导入照片开始修图

[查看仓库](https://github.com/storytold/lightcraft)

**omnivore-app/omnivore**

- [ ] 参考 README 里的自托管指南部署
- [ ] 部署完成后用浏览器或 App 登录使用

[查看仓库](https://github.com/omnivore-app/omnivore)

**langchain-ai/langchain**

★147.4k · Python

一套帮开发者搭建 AI 应用的工具箱，把大模型和各种功能拼起来用。

**核心亮点**

- 把大模型和外部工具连接起来
- 提供现成组件，减少重复开发
- 可搭配 Deep Agents 做复杂任务

**应用与部署指南**

面向开发者，需要先装 Python 环境，用 uv 安装后即可在代码里调用。使用前通常要准备大模型服务的 API Key。

- [ ] 先安装 Python 环境
- [ ] 运行 uv add langchain 安装
- [ ] 在代码里初始化模型并调用

```bash
uv add langchain
```

[查看仓库](https://github.com/langchain-ai/langchain)
