# GitHub 热门效率与 AI 工具

*让 AI 与自动化更顺手地融入日常输入、搜索与数据采集*

**freestylefly/WeChatBridge**

★819 · Swift · 近期趋势

把微信聊天记录一键转发给 AI 助手或笔记软件，省去复制粘贴的麻烦。

**核心亮点**

- 微信转发菜单里直接选目标应用
- 一键把聊天记录发给 Codex、Claude 等 AI
- 自动生成 Markdown 笔记存进 Obsidian
- 转发失败时文件仍保留在剪贴板

**应用与部署指南**

这是 macOS 上的原生小工具，需先下载安装 DMG 包，并给微信开启转发权限；装好后在微信多选聊天记录、点合并转发即可使用。

- [ ] 下载并安装 WeChatBridge 的 DMG 安装包
- [ ] 在微信中多选聊天记录并选择合并转发
- [ ] 在转发菜单里选择目标 AI 或 Obsidian

[查看仓库](https://github.com/freestylefly/WeChatBridge)

**qingjian-team/qingjian**

★2k · Rust · 近期趋势

一个拼音输入法，打字时在候选词旁顺带显示正在学的外语翻译。

**核心亮点**

- 打拼音出中文，候选旁附外语译词
- 一次只显示一种学习语言，不干扰输入
- 支持中文、英文、日语等语言切换
- 整句拼音输入，本地模型自动重排候选

**应用与部署指南**

去官网下载 macOS 或 Windows 安装包，装好后在系统输入法设置里添加青简并切换使用；Windows 版目前还在内测。

- [ ] 访问 qingjian.app/download 下载安装包
- [ ] 安装后在系统输入法设置中添加青简
- [ ] 设置主语言和学习语言后开始打字

[查看仓库](https://github.com/qingjian-team/qingjian)

**Flow-Launcher/Flow.Launcher**

★15.7k · C#

Windows 上的快速启动器，敲几个键就能搜到应用、文件和网页书签。

**核心亮点**

- 一键搜索应用、文件和文件内容
- 支持网页搜索和浏览器书签
- 可安装社区插件扩展功能
- 支持快捷键呼出，操作不离开键盘

**应用与部署指南**

Windows 10 及以上系统可用，通过 winget、Scoop 或 Chocolatey 安装，也可下载安装包或便携版；首次安装时系统可能提示未签名，从官方仓库下载即可继续。

- [ ] winget install "Flow Launcher"
- [ ] 首次启动后按提示完成设置
- [ ] 用默认快捷键呼出并开始搜索

[查看仓库](https://github.com/Flow-Launcher/Flow.Launcher)

**lobehub/lobehub**

★82.8k · TypeScript

一个管理 AI 助手的平台，帮你安排、调度并汇报整个 AI 团队的工作。

**核心亮点**

- 把多个 AI 助手组织成团队统一管理
- 支持定时调度和自动汇报工作
- 可自建部署，数据自己掌控
- 提供插件生态扩展 AI 能力

**应用与部署指南**

可以部署到 Vercel、Zeabur 等云平台，也可以用 Docker 自建；使用前需要准备 OpenAI API Key，具体环境变量见官方文档。

- [ ] 选择 Vercel 或 Docker 方式部署
- [ ] 配置环境变量并填入 OpenAI API Key
- [ ] 启动后访问网页即可管理 AI 团队

[查看仓库](https://github.com/lobehub/lobehub)

**D4Vinci/Scrapling**

★84k · Python

一个网页数据采集工具，网站改版后也能自动找回要抓的内容。

**核心亮点**

- 网站改版后自动重新定位目标元素
- 能绕过 Cloudflare 等反爬拦截
- 支持大规模并发抓取和断点续爬
- 自动轮换代理并调节抓取速度

**应用与部署指南**

用 Python 编写，通过 pip 安装后即可在代码里调用；支持单次请求到大规模爬取，也提供命令行和 MCP 接口。

- [ ] 用 pip 安装 Scrapling 库
- [ ] 在 Python 代码中导入 Fetcher 等模块
- [ ] 调用 fetch 方法抓取目标网页数据

[查看仓库](https://github.com/D4Vinci/Scrapling)
