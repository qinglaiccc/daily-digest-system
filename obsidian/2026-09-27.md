**yetone/magpie**

★1k · Go · 近期趋势

一个菜单栏小工具，集中查看并切换电脑上各个 AI 助手用的模型。

**核心亮点**

- 一屏列出所有 AI 助手当前用的模型
- 点一下就能给某个助手换模型
- 改配置只动那一行，注释和排版不丢
- 支持 macOS、Linux 和 Windows

**应用与部署指南**

装好后从菜单栏点图标打开面板，点数值选模型即可；也有终端版和命令行版。README 未给出具体安装命令，需自行查看项目说明。

- [ ] 查看项目 README 获取安装方式
- [ ] 安装后从菜单栏点击 magpie 图标打开面板
- [ ] 点击某个助手的模型值，选择新模型

[查看仓库](https://github.com/yetone/magpie)

**Ryze-AI-Adgent/open-seo-mcp-skills**

★2.1k · Shell · 近期趋势

给 Claude 加一套免费 SEO 技能，用你自己的网站数据做关键词和排名分析。

**核心亮点**

- 用真实搜索数据查关键词和排名
- 看竞争对手的关键词和外链差距
- 统计来自 AI 聊天工具的访问量
- 技能代码开源，可自由修改

**应用与部署指南**

需要先有 Claude 环境，把 Ryze 连接器加到 Claude 里，再装技能插件；数据来自你自己的搜索后台和广告账号。

- [ ] claude mcp add ryze --transport http https://connector.get-ryze.ai/mcp
- [ ] claude plugin marketplace add Ryze-AI-Adgent/open-seo-mcp-skills
- [ ] 按 README 说明连接你的搜索和广告数据

[查看仓库](https://github.com/Ryze-AI-Adgent/open-seo-mcp-skills)
