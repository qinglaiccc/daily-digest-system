# GitHub 热门效率与 AI 工具

**dzhng/jevgrep**

★1.4k · TypeScript · 近期趋势

用一句话描述需求，就能帮你找出相关代码文件的命令行小工具。

**核心亮点**

- 用大白话提问，直接返回相关文件
- 附带原文代码片段和阅读线索
- 支持 Claude Code、Codex 等编程助手

**应用与部署指南**

需要先装 Node.js 22 以上版本，仅支持 macOS 或 Linux，还要准备一个 AI 服务的密钥。装好后运行授权命令，再安装技能包，就能在项目里提问找代码。

- [ ] 先安装 Node.js 22 或更高版本
- [ ] 运行 npm install -g @dzhng/jevgrep
- [ ] 运行 jg auth 完成授权
- [ ] 运行 jg skill 安装技能包
- [ ] 运行 jg "问题" ./项目路径 开始提问

```bash
npm install -g @dzhng/jevgrep
```

[查看仓库](https://github.com/dzhng/jevgrep)
