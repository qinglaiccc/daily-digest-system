**omlahore/RemoveMacAI**

★3.1k · Swift · 近期趋势

给 Mac 关掉苹果 AI、广告和弹窗，还能腾出硬盘空间，改动都能撤销。

**核心亮点**

- 一键关闭苹果智能并删除其模型文件
- 关掉系统分析和广告弹窗
- 关闭其他软件的后台自动更新
- 所有改动可随时还原

**应用与部署指南**

在 Mac 的终端里粘贴一行命令即可安装图形版应用，装好后在「应用程序」里打开；首次打开需到系统设置里点「仍要打开」。

- [ ] 打开终端（应用程序 > 实用工具）
- [ ] 粘贴 README 中的安装命令并回车
- [ ] 首次打开到系统设置点「仍要打开」

```bash
curl -fsSL https://raw.githubusercontent.com/omlahore/RemoveMacAI/main/install.sh | bash -s app
```

**langgenius/dify**

★158k · TypeScript

一个搭 AI 应用的工作台，拖拖拽拽就能做出带 AI 的流程和问答系统。

**核心亮点**

- 在画布上可视化搭建 AI 工作流
- 支持多种 AI 模型和工具接入
- 内置知识库问答（RAG）能力
- 可云端用也可自己部署

**应用与部署指南**

需要电脑有 2 核 CPU、4GB 内存，并先装好 Docker 和 Docker Compose；用几条命令启动后，浏览器打开本地地址初始化即可。

- [ ] 确认电脑满足 2 核 CPU、4GB 内存
- [ ] 安装 Docker 和 Docker Compose
- [ ] 进入 dify/docker 目录复制配置文件
- [ ] 运行 docker compose up -d 启动
- [ ] 浏览器打开 http://localhost/install 初始化

```bash
docker compose up -d
```
