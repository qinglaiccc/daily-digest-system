# GitHub 热门效率与 AI 工具

*让旧设备与 AI 助手更好用的效率工具合集*

**trustno1-coder/VIctory-NVIDIA**

★3.1k · Rust · 近期趋势

让 Xbox 游戏在 NVIDIA 显卡电脑上跑起来并提升画质的兼容工具

**核心亮点**

- 在电脑上运行 Xbox Series 游戏
- 用 DLSS 提升画面并插帧提速
- 按 F1 调设置、F3 看帧数

**应用与部署指南**

面向 Windows 电脑，需要 NVIDIA 显卡（RTX 40/50 支持 DLSS 插帧，20/30 系用 FSR 插帧）。README 未给出安装命令，需自行获取程序运行。

- [ ] 准备 Windows 10 或 11 与 NVIDIA 显卡
- [ ] 运行 victory.exe 或脚本启动器
- [ ] 按 F1 打开设置菜单调整画质

[查看仓库](https://github.com/trustno1-coder/VIctory-NVIDIA)

**ersinkoc/phonebox**

★7.7k · JavaScript · 近期趋势

把闲置安卓手机变成电脑副屏和触控面板的工具

**核心亮点**

- 手机实时显示电脑 CPU、内存等状态
- 查看 AI 编程工具的用量和进度
- 用手机当快捷键和媒体控制台

**应用与部署指南**

电脑装桌面端小助手，手机装配套安卓 App，用 USB 或 Wi-Fi 连接即可，无需 root 或账号。支持 Windows、Linux、macOS。

- [ ] 在电脑上安装 PhoneBox 桌面端
- [ ] 在安卓手机上安装 PhoneBox App
- [ ] 用 USB 或 Wi-Fi 将手机与电脑配对
- [ ] 在浏览器编辑器里拖拽搭建面板

[查看仓库](https://github.com/ersinkoc/phonebox)

**lissy93/dashy**

★27.1k · Vue

自建一个属于自己的网址导航首页，集中管理常用服务和网站

**核心亮点**

- 实时显示各服务是否在线
- 用小组件展示自建服务的信息
- 支持多页面、主题和图标自定义

**应用与部署指南**

适合有自己服务器或 NAS 的人。可用 Docker 部署，也可用 Node.js 运行，装好后在浏览器里编辑配置。

- [ ] 准备一台可运行 Docker 或 Node.js 的机器
- [ ] 按官方文档选择 Docker 或 Node 方式部署
- [ ] 打开网页进入配置编辑器添加链接

[查看仓库](https://github.com/lissy93/dashy)

**pbakaus/impeccable**

★118k · Rust

给 AI 编程助手补上设计词汇，让它做出的页面不再千篇一律

**核心亮点**

- 用 polish、bolder 等词指挥 AI 改设计
- 用 critique、audit 检查页面问题
- 在成品上线前拦住模板化设计

**应用与部署指南**

在项目根目录运行安装命令，然后重载你的 AI 编程工具，在助手内执行初始化命令即可。需要先装 Node.js。

- [ ] 先安装 Node.js 环境
- [ ] 在项目根目录运行 npx impeccable install
- [ ] 重载你的 AI 编程工具
- [ ] 在助手里运行 /impeccable init

```bash
npx impeccable install
```

[查看仓库](https://github.com/pbakaus/impeccable)
