# GitHub 热门效率与 AI 工具

*从本地出图、决策模型到笔记与工作流自动化，让 AI 真正落到日常干活里。*

**Arekejoker/qwen21-nsfw-pose-skill**

★2.6k · Python · 近期趋势

一套本地 AI 出图配方，帮你用固定姿势和提示词稳定生成人物图。

**核心亮点**

- 内置 136 个 3D 人偶姿势，可精确控制人物动作
- 提供作者级提示词模板和分级大胆度参考
- 可接入 Claude Code、Cursor 等 AI 助手当技能用
- 附带自检脚本，检查环境缺什么

**应用与部署指南**

需要先装好 ComfyUI 和对应底模、LoRA 与姿势节点，按仓库 install/setup.md 配置后，用 Python 脚本自检并跑示例。适合有一定本地出图环境的人。

- [ ] 按 install/setup.md 安装 ComfyUI 与依赖
- [ ] python3 scripts/doctor.py 检查环境
- [ ] python3 scripts/qwen_pose_test.py 跑作者案例

```bash
python3 scripts/doctor.py
```

[查看仓库](https://github.com/Arekejoker/qwen21-nsfw-pose-skill)

**jaredpalmer/kev**

★9.3k · Python · 近期趋势

一组能自己训练和运行的小型决策模型，专门回答是/否、选择和打分问题。

**核心亮点**

- 一次请求可问是/否、多选和评分三类问题
- 默认输出经过校准的概率，结果更可信
- 提供从笔记本到单卡服务器的四种大小
- 支持用自己标注的数据微调

**应用与部署指南**

可先在 Hugging Face 网页上试用；本地运行需要 Python 环境，按模型卡选择合适尺寸，有 GPU 或苹果芯片更顺畅。

- [ ] 访问 huggingface.co/spaces/jaredpalmer/kev 在线试用
- [ ] 按模型卡选择 Kev-4B 等合适尺寸
- [ ] 准备 Python 环境加载预训练权重

[查看仓库](https://github.com/jaredpalmer/kev)

**YishenTu/claudian**

★15.7k · TypeScript

把 AI 编程助手塞进 Obsidian 笔记软件，让它在你的笔记库里读写文件、跑命令。

**核心亮点**

- 在笔记里直接让 AI 读写、搜索和修改文件
- 选中文字即可用快捷键就地编辑并预览差异
- 支持斜杠命令、@提及文件和多个会话互通
- 可切换 Claude Code、Codex 等多种助手

**应用与部署指南**

先在 Obsidian 里安装并启用该插件，再从侧边栏图标或命令面板打开界面；需要自备对应 AI 服务的账号或密钥。

- [ ] 在 Obsidian 中安装并启用 Claudian 插件
- [ ] 从侧边栏图标或命令面板打开界面
- [ ] 配置所用 AI 助手的账号或密钥

[查看仓库](https://github.com/YishenTu/claudian)

**NousResearch/hermes-agent**

★254.7k · Python

一个会自己积累经验、越用越懂你的 AI 助手，可跑在云端并随时从聊天软件找它。

**核心亮点**

- 完成任务后自动总结成可复用的技能
- 记住过往对话，跨会话延续对你的了解
- 可在 Telegram、Slack 等聊天软件里指挥
- 支持切换多种模型，不绑定单一厂商

**应用与部署指南**

可部署在便宜的云服务器或本地，通过终端界面或聊天软件使用；需要自备模型服务（如 OpenRouter、OpenAI）的账号。

- [ ] 准备一台服务器或本地环境
- [ ] 配置所用模型服务的账号或密钥
- [ ] 用 hermes model 切换模型后开始对话

[查看仓库](https://github.com/NousResearch/hermes-agent)

**n8n-io/n8n**

★207.8k · TypeScript

一个可视化搭自动化流程的工具，把各种软件和 AI 串起来替你干活。

**核心亮点**

- 拖拽画布搭建多步骤 AI 工作流
- 连接 1500 多个外部服务，如表格和邮件
- 需要时可插入 JavaScript 或 Python 代码
- 可自建部署，数据留在自己手里

**应用与部署指南**

需要先装 Docker，用官方脚本或 Docker 命令启动，然后在浏览器打开 localhost:5678 使用；也可直接用云端版。

- [ ] 先安装 Docker
- [ ] curl -fsSL https://get.n8n.io | sh 一键安装
- [ ] 浏览器访问 http://localhost:5678 开始搭建

```bash
curl -fsSL https://get.n8n.io | sh
```
