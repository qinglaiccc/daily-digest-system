**storytold/filmcraft**

★3.3k · Rust · 近期趋势

一个免费开源的视频剪辑软件，对标 Adobe Premiere Pro，能在电脑和浏览器里用。

**核心亮点**

- 剪辑、调色、音效、字幕一站完成
- 支持 macOS、Windows、Linux 和浏览器
- 用公开素材就能剪出成片

**应用与部署指南**

README 未给出安装命令，可先访问官网 getartcraft.com/apps/filmcraft 了解下载方式；浏览器版打开网页即可试用。

- [ ] 访问官网 getartcraft.com/apps/filmcraft
- [ ] 按页面提示选择对应系统版本

[查看仓库](https://github.com/storytold/filmcraft)

**Ebony-Vinyl/dsh-our-free-model**

★3.4k · JavaScript · 近期趋势

给 dsh 装个插件，不用注册、不用填密钥，就能免费用上 DeepSeek、Kimi 等前沿模型。

**核心亮点**

- 无需登录注册，装上就能用
- 免费不限量，模型清单自动更新
- 设置页一键升级，改完即时生效

**应用与部署指南**

前提是你已经在用 dsh 这个工具；在 dsh 里安装本插件即可，无需账号、密钥或后台申请配额，纯插件挂载、零依赖。

- [ ] 先安装并打开 dsh 工具
- [ ] 在 dsh 中安装本插件
- [ ] 打开设置页确认可用模型列表

[查看仓库](https://github.com/Ebony-Vinyl/dsh-our-free-model)

**rowboatlabs/rowboat**

★18k · TypeScript

一个开源的私人 AI 助理，自带邮件、笔记和白板，能记住你的工作内容帮你干活。

**核心亮点**

- 自动整理邮件并起草回复

提供 Mac、Windows、Linux 安装包，从 README 的 Download 链接下载安装即可；无需自己搭服务器，装好就能用。

- [ ] 打开 README 中的 Download 链接
- [ ] 下载对应系统的安装包
- [ ] 安装后启动并按引导配置

[查看仓库](https://github.com/rowboatlabs/rowboat)

**open-webui/open-webui**

★154.2k · Python

- [ ] 启动后用浏览器打开访问

**DietrichGebert/ponytail**

★157.6k · JavaScript

给 AI 编程助手装上一段提示词，让它像老练工程师一样少写代码、只写有用的。

**核心亮点**

- 让 AI 少写约一半代码
- 同样任务更省钱、跑得更快
- 支持 Claude Code、Codex 等助手

**应用与部署指南**

本质是一段提示词，装进你正在用的 AI 编程助手即可；Claude Code 和 Codex 有现成插件命令，其他助手可复制 AGENTS.md 到项目里。

- [ ] /plugin marketplace add DietrichGebert/ponytail
- [ ] /plugin install ponytail@ponytail
- [ ] 其他助手复制 AGENTS.md 到项目

[查看仓库](https://github.com/DietrichGebert/ponytail)
