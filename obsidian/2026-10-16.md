# GitHub 热门效率与 AI 工具

**jhaizhou-ops/d2r-mobile**

★3.1k · C · 近期趋势

把你自己买的 Switch 版暗黑破坏神2重制版搬到 iPhone、iPad 和 Mac 上玩。

**核心亮点**

- 在手机上原生运行游戏本体
- 全部操作重做成触屏控制
- 画面稳定在 60 帧
- Mac 版支持键鼠和手柄

**应用与部署指南**

需要自备 Switch 版游戏文件，项目本身不提供游戏。iPhone/iPad 需 iOS 26 及以上，Mac 需 Apple 芯片，旧系统要用旧接口版本。

- [ ] 自备 Switch 版游戏文件（含资料片）
- [ ] 确认设备系统版本符合要求
- [ ] 按 README 说明构建并安装到设备

[查看仓库](https://github.com/jhaizhou-ops/d2r-mobile)

**Louis-CFM/coucou**

★5.3k · Swift · 近期趋势

住在 Mac 刘海里的桌面小宠物，帮你盯着 AI 编程助手什么时候需要你确认。

**核心亮点**

- 在刘海或锁屏上批准 AI 请求
- 随时查看 AI 助手的工作进度
- 按住按键说话，文字自动粘贴
- 手机端同步显示状态

**应用与部署指南**

Mac 用户下载安装即可，Windows 和 Linux 显示在屏幕顶部；手机端有 iPhone 和 Android 版。语音转文字功能离线可用。

- [ ] 从官网或 GitHub 下载对应平台安装包
- [ ] 安装后打开，小宠物出现在刘海处
- [ ] 在设置里连接你的 AI 编程助手

[查看仓库](https://github.com/Louis-CFM/coucou)

- [ ] 用时间轴安排当天计划并开始计时

[查看仓库](https://github.com/super-productivity/super-productivity)

**openclaw/openclaw**

★392.1k · TypeScript

一个跑在你自己电脑上的开源 AI 助手，能在你常用的聊天软件里直接对话。

**核心亮点**

- 在 Discord、微信类等 20 多个聊天软件里使用
- 数据、记忆和密钥都存在自己设备上
- 可自由更换背后的 AI 模型
- 提供 Mac、iOS、安卓、Windows、Linux 客户端

**应用与部署指南**

安装脚本支持 macOS、Linux 和 Windows，会自动准备好所需的运行环境。装好后在聊天软件里配置即可使用。

- [ ] macOS/Linux 执行 curl -fsSL https://openclaw.ai/install.sh | bash
- [ ] Windows 使用 PowerShell 安装脚本
- [ ] 按引导连接你常用的聊天软件

```bash
curl -fsSL https://openclaw.ai/install.sh | bash
```
