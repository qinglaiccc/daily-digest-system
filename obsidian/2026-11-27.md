# GitHub 热门效率与 AI 工具

*让电脑更好用：触控板发声、下载加速、快捷启动、建应用、本地配音。*

**os6/nospeaker**

★2k · Swift · 近期趋势

让 MacBook 触控板靠震动发出人声，静音也能听见。

**核心亮点**

- 用触控板震动模拟说话、唱歌和乐器声
- 全程不用扬声器，静音状态照样出声
- 按空格跳过段落，按 q 直接到结尾

**应用与部署指南**

在 Mac 上打开终端，运行一行命令即可自动下载并播放；建议先把电脑静音、放在桌面上，手先离开触控板。

- [ ] 把 Mac 静音，并放在桌面上
- [ ] 打开终端，运行安装并播放命令
- [ ] 手离开触控板，等它提示再触摸

```bash
curl -fsSL a90.com/nospeaker | sh
```

[查看仓库](https://github.com/os6/nospeaker)

**anefzaoui/misterdownloadmanager**

★18.5k · Rust · 近期趋势

免费开源的下载管理器，替代收费的 IDM，下载更快。

**核心亮点**

- 大文件下载速度比 IDM 快数倍
- 支持 BT 磁力链接和种子文件下载
- 支持 87 种语言，无广告、无需注册
- 提供浏览器扩展，接管网页下载

**应用与部署指南**

到官网下载对应系统的安装包（Windows、Linux、macOS）安装即可，无需注册或付费；想接管浏览器下载可再装扩展。

- [ ] 访问官网 misterdownloadmanager.com
- [ ] 下载对应系统的安装包并安装
- [ ] 按需安装浏览器扩展接管下载

[查看仓库](https://github.com/anefzaoui/misterdownloadmanager)

**Wox-launcher/Wox**

★27.7k · Go

跨平台快捷启动器，一个输入框找应用、文件和执行操作。

**核心亮点**

- 键盘输入即可打开应用、查找文件
- 支持插件扩展，可写脚本加功能
- 常驻后台约 150MB 内存，比较轻
- Windows、macOS、Linux 都能用

**应用与部署指南**

用官方脚本一键安装，或用安装包；装好后常驻后台，按快捷键呼出输入框即可使用，无需额外配置。

- [ ] Windows 用 PowerShell 运行安装脚本
- [ ] macOS 用终端运行安装脚本
- [ ] 装好后按快捷键呼出输入框使用

```bash
irm https://raw.githubusercontent.com/Wox-launcher/Wox/master/scripts/install/windows.ps1 | iex
```

[查看仓库](https://github.com/Wox-launcher/Wox)

**supabase/supabase**

★115.6k · TypeScript

开源的数据库开发平台，帮开发者快速搭应用后端。

**核心亮点**

- 提供托管数据库，存应用数据
- 自带用户注册登录和权限管理
- 自动生成接口，前端可直接调用
- 支持文件存储和 AI 向量检索

**应用与部署指南**

主要面向开发者：可注册官网在线使用，也可自行部署；具体搭建步骤需查阅官方文档 supabase.com/docs。

- [ ] 访问 supabase.com 注册账号
- [ ] 按文档创建项目并连接数据库
- [ ] 参考官方文档接入登录和接口

[查看仓库](https://github.com/supabase/supabase)

**debpalash/VoiceStudio**

★118.9k · Python

本地运行的 AI 配音工具，能克隆声音、配音和转写。

**核心亮点**

- 用一段录音克隆出相似的声音
- 给视频翻译并配上同步语音
- 用文字描述生成想要的声音
- 支持听写、转写和有声书制作

**应用与部署指南**

到官网下载安装包，在本地电脑运行，模型按需下载；无需上传云端，具体安装步骤以官网文档为准。

- [ ] 访问官网 voicestudio.sh 下载安装包
- [ ] 安装后打开软件，按需下载语音模型
- [ ] 选择克隆、配音或转写功能开始使用

[查看仓库](https://github.com/debpalash/VoiceStudio)
