# GitHub 热门效率与 AI 工具

*让 AI 真正替你动手：操作手机、克隆应用、写代码、管终端。*

**wangzan101/Mika**

★2.7k · Kotlin · 近期趋势

装在安卓手机上的 AI 助理，说一句话它就替你在后台操作 App、上网办事。

**核心亮点**

- 在后台屏操作 App，不占用你的手机屏幕
- 像人一样看屏幕找按钮，无需 App 开放接口
- 内置浏览器，可对着当前网页下指令
- 记住你的偏好，办成的事自动总结成技能

**应用与部署指南**

从 Releases 下载 APK 装到安卓手机上，在设置里填入自己的模型 API Key 或登录账号；要操作其他 App 时需按向导配对一次无线调试。

- [ ] 从 Releases 页面下载 APK 并安装
- [ ] 在设置›模型里填 API Key 或登录账号
- [ ] 要操作 App 时按向导配对无线调试

[查看仓库](https://github.com/wangzan101/Mika)

**Jakeschincariol/replica-skill**

★6.8k · Python · 近期趋势

一套给 Claude 用的技能包，帮你拆解并重做一个 App，还能修掉原版用户吐槽的毛病。

**核心亮点**

- 逆向分析目标 App 的功能与流程
- 按分析结果重新搭建一个同类应用
- 自动测试新应用并找出 bug
- 参考原版用户差评改进你的版本

**应用与部署指南**

需要先有 Claude 或 Claude Code 环境，把仓库地址粘给 Claude 说 install skill，或在 Claude Code 里用插件命令安装，无需注册和 API Key。

- [ ] 在 Claude 中粘贴仓库地址并说 install skill
- [ ] 或在 Claude Code 执行 /plugin marketplace add Jakeschincariol/replica-skill
- [ ] 再执行 /plugin install replica-skill@replica-skill

```bash
/plugin marketplace add Jakeschincariol/replica-skill
```

[查看仓库](https://github.com/Jakeschincariol/replica-skill)

**wavetermdev/waveterm**

★22.6k · Go

一个带 AI 助手的开源终端工具，把命令行、文件编辑和网页浏览放在同一个窗口里。

**核心亮点**

- AI 助手能读终端输出并帮你操作文件
- 远程连接断网后自动重连，不丢会话
- 内置编辑器可直接改远程文件
- 拖拽排布终端、编辑器、浏览器等区块

**应用与部署指南**

支持 macOS、Linux、Windows，从官网下载安装包即可使用；AI 功能需自备 OpenAI、Claude 等 API Key，或用本地模型，无需注册账号。

- [ ] 从官网下载对应系统的安装包
- [ ] 安装后打开 Wave 终端
- [ ] 在设置中填入自己的 AI 模型 API Key

[查看仓库](https://github.com/wavetermdev/waveterm)

**obra/superpowers**

★310k · Shell

给写代码的 AI 助手定的一套工作方法，让它先问清需求再动手，而不是上来就写代码。

**核心亮点**

- 先和你确认需求，再分段展示方案
- 生成清晰到新手能照做的实施计划
- 强调先写测试再写代码的开发流程
- 支持 Claude Code、Cursor 等多种工具

**应用与部署指南**

需要先装好你常用的 AI 编程工具（如 Claude Code、Cursor、Codex），再按 README 对应章节的说明把技能装进去。

- [ ] 先安装 Claude Code、Cursor 等编程工具
- [ ] 按 README 中对应工具的章节安装技能

[查看仓库](https://github.com/obra/superpowers)

**affaan-m/ECC**

★294.1k · JavaScript

给 AI 编程助手加装的一套增强系统，补上记忆、安全检查和技能，让它干活更稳。

**核心亮点**

- 为 AI 助手提供技能与记忆能力

- [ ] 先安装 Claude Code
- [ ] 在 Claude Code 中执行引导式安装或插件安装
- [ ] 确认插件来源为官方 ecc@ecc
