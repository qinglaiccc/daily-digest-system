# GitHub 热门效率与 AI 工具

*从教学知识图谱到视频剪辑与 AI 应用搭建，帮人把复杂活儿变简单。*

**xiaoyang111222/cn-math-taxonomy**

★2.2k · Python · 近期趋势

把中小学数学英语物理知识点串成一张网，答错题能一路追溯到最基础的小学概念。

**核心亮点**

- 收录 1644 个知识点和 6723 道题
- 答错题自动回溯到薄弱前置知识
- 数学、英语、物理各自成图
- 提供在线诊断工具可直接试用

**应用与部署指南**

普通用户直接打开官网在线试用诊断即可；想自己部署需有 Python 环境，按仓库说明运行。

- [ ] 访问 math.pansgo.com 在线试用诊断
- [ ] 想本地跑需先安装 Python 环境
- [ ] 按仓库说明启动本地服务

[查看仓库](https://github.com/xiaoyang111222/cn-math-taxonomy)

**storytold/filmcraft**

★15.7k · Rust · 近期趋势

一款免费开源的视频剪辑软件，界面和快捷键跟专业软件一样，电脑和浏览器都能用。

**核心亮点**

- 多轨道剪辑、调色、音效和字幕
- 支持 macOS、Windows、Linux 和网页
- 每个操作都能交给 AI 助手执行
- 自带视频编解码，不依赖外部组件

**应用与部署指南**

普通用户去官网下载对应系统的安装包即可；想在浏览器用直接打开网页版，无需装环境。

- [ ] 访问 getartcraft.com/apps/filmcraft
- [ ] 下载对应系统的安装包
- [ ] 安装后打开即可开始剪辑

[查看仓库](https://github.com/storytold/filmcraft)

**jarun/nnn**

★22.1k · C

在命令行里管理文件的小工具，体积只有 150KB，却比图形文件管理器还快。

**核心亮点**

- 分析磁盘占用，找出大文件
- 批量重命名文件
- 插件扩展实时预览、挂载磁盘
- 在手机 Termux 和树莓派上也能跑

**应用与部署指南**

面向习惯命令行的用户，需先装好系统包管理器，按 README 的安装章节用包管理器或源码编译安装。

- [ ] 用系统包管理器安装 nnn
- [ ] 或按 README 说明从源码编译
- [ ] 终端输入 nnn 启动

[查看仓库](https://github.com/jarun/nnn)

**langgenius/dify**

★159.3k · Python

一个可视化搭 AI 应用的工作台，拖拖拽拽就能把大模型接进自己的业务流程。

**核心亮点**

- 在画布上拖拽搭建 AI 工作流
- 接入多种大模型统一管理
- 内置知识库问答（RAG）能力
- 支持云端或自己服务器部署

**应用与部署指南**

需先装 Docker 和 Docker Compose（2.24.0 以上），机器至少 2 核 CPU、4GB 内存，用几条命令启动后浏览器打开本地地址初始化。

- [ ] 先安装 Docker 和 Docker Compose v2.24.0+
- [ ] 确认机器至少 2 核 CPU、4GB 内存
- [ ] cd dify 后进入 docker 目录
- [ ] cp .env.example .env
- [ ] docker compose up -d 后访问 localhost/install

```bash
docker compose up -d
```

[查看仓库](https://github.com/langgenius/dify)
