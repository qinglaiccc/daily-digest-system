**KKKKhazix/agent-autoloop**

★2.5k · TypeScript · 近期趋势

让命令行 AI 助手在后台自己接活干到底，拿不准时才发消息问你

**核心亮点**

- 关掉终端，任务照样在后台跑完
- 需要你拍板时推送到飞书、钉钉、Slack
- 一行配置就能接入新的 AI 助手
- 敲一行命令查看整体进展和花费

**应用与部署指南**

支持 macOS 和 Linux，需先装好 Node 24、Git、curl，以及一个已登录的命令行 AI 助手；用一条安装脚本装好后即可试跑。Windows 版暂未推出。

- [ ] 先安装 Node 24、Git 和 curl
- [ ] 准备一个已登录的命令行 AI 助手
- [ ] 运行安装脚本 curl -fsSL https://raw.githubusercontent.com/KKKKhazix/agent-autoloop/main/install.sh | sh
- [ ] 运行 agent-autoloop try 走一遍试跑流程

```bash
curl -fsSL https://raw.githubusercontent.com/KKKKhazix/agent-autoloop/main/install.sh | sh
```

[查看仓库](https://github.com/KKKKhazix/agent-autoloop)

**HeyPuter/everything**

★7.1k · JavaScript · 近期趋势

把 Excel、Word、Photoshop 这类收费软件重做成免费开源版的合集

**核心亮点**

- 表格、文档、演示等办公软件替代品
- 会议、白板等协作工具替代品
- 创意、工程、财务等多类软件替代
- 所有应用源码集中在一个仓库里

**应用与部署指南**

需要先装 Node.js 22.12 或更新版本；把仓库下载到本地，进入想用的那个应用目录，装依赖后启动开发模式即可在浏览器里用。

- [ ] 先安装 Node.js 22.12 或更新版本
- [ ] 运行 git clone https://github.com/HeyPuter/everything.git
- [ ] 运行 cd everything/src/[app-name] 进入某个应用目录
- [ ] 运行 npm install 安装依赖
- [ ] 运行 npm run dev 启动

```bash
git clone https://github.com/HeyPuter/everything.git
```

[查看仓库](https://github.com/HeyPuter/everything)
