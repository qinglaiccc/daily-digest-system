# GitHub 热门效率与 AI 工具

*让普通人也能用上 AI 与自动化：从热点日报到浏览器操控。*

**nullmoth/nvidia-macos-driver**

★2.9k · Rust · 近期趋势

让装了英伟达显卡的 Mac 或黑苹果电脑，也能正常用上图形加速。

**核心亮点**

- 支持 RTX 20 到 50 系列等较新显卡
- 支持光线追踪、网格着色等图形效果
- 附带一个 Mac 应用，可发送日志排查问题

**应用与部署指南**

需要先让电脑能用 OpenCore 启动 macOS 15，再安装驱动；仓库提供 Mac 应用和安装包，普通用户按文档操作即可。

- [ ] 先用 OpenCore 让电脑能启动 macOS 15
- [ ] 从 releases 页面下载驱动安装包
- [ ] 安装驱动并重启电脑
- [ ] 用 1401 应用发送日志排查问题

[查看仓库](https://github.com/nullmoth/nvidia-macos-driver)

**KKKKhazix/AIHOT**

★7.5k · TypeScript · 近期趋势

一个能自己找热点、自己写日报的网站框架，换成你的行业信源就能用。

**核心亮点**

- 自动从多种信源收集资料并筛选
- 用大模型写中文标题和摘要
- 把同一件事聚成一个事件并排热度
- 每天早上自动生成一份日报

**应用与部署指南**

需要自己准备大模型接口和信源，用 Docker Compose 跑起来；仓库带 18 个公开 AI 资讯源做示范，换成你行业的信源即可。

- [ ] 准备大模型接口和行业信源
- [ ] 用 Docker Compose 启动服务
- [ ] 在配置里换成自己的信源和标准
- [ ] 访问网站查看自动生成的日报

[查看仓库](https://github.com/KKKKhazix/AIHOT)

**lissy93/dashy**

★26.7k · Vue

一个可以自己搭建的个人主页，把常用网站和服务集中到一个页面。

**核心亮点**

- 实时显示各个应用和链接的状态
- 用小组件展示自建服务的信息
- 支持搜索、快捷键和多种主题
- 带界面编辑器，改配置不用写代码

**应用与部署指南**

可以自己用 Node 或 Docker 跑在本地或服务器上，也可以直接用官方在线演示；需要先装 Node 或 Docker。

- [ ] 先安装 Node.js 或 Docker
- [ ] 按文档用 Docker 或 Node 启动 Dashy
- [ ] 打开浏览器访问本地地址
- [ ] 在界面编辑器里添加自己的链接

[查看仓库](https://github.com/lissy93/dashy)

**puppeteer/puppeteer**

★95.7k · TypeScript

让程序自动操控 Chrome 或 Firefox 浏览器，代替人做重复操作。

**核心亮点**

- 用代码自动打开网页、点击和填表
- 默认在后台运行，不弹出浏览器窗口
- 可用来做网页测试和自动抓取

**应用与部署指南**

需要先装 Node.js，然后用 npm 安装；安装时会自动下载配套浏览器，如果被拦截可手动下载。

- [ ] 先安装 Node.js
- [ ] 运行 npm i puppeteer 安装
- [ ] 若浏览器未下载，运行 npx puppeteer browsers install
- [ ] 在代码里调用 puppeteer 启动浏览器

```bash
npm i puppeteer
```

[查看仓库](https://github.com/puppeteer/puppeteer)
