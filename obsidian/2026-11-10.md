# GitHub 热门效率与 AI 工具

*让游戏、炒股、阅读和写代码更省事的开源工具*

**jhaizhou-ops/S2Arm**

★1.7k · C# · 近期趋势

把你自己买的 Switch 游戏搬到 iPhone、iPad 和 Mac 上原生运行，不用模拟器。

**核心亮点**

- 游戏直接跑在设备芯片上，不经过模拟器
- 所有游戏装进同一个 App，不用反复安装
- 在 Mac 或 Windows 上点几下就能导入游戏

**应用与部署指南**

需要自备游戏文件和密钥，先在 Mac 或 Windows 上装启动器，把游戏导入后装到 iPhone、iPad 或 Mac 上玩。系统要求 iOS/iPadOS 18 以上或 Apple 芯片 Mac 的 macOS 15 以上。

- [ ] 准备你自己的 Switch 游戏文件和密钥
- [ ] 在 Mac 或 Windows 上安装启动器
- [ ] 用启动器导入游戏并生成 App
- [ ] 装到 iPhone、iPad 或 Mac 上运行

[查看仓库](https://github.com/jhaizhou-ops/S2Arm)

**Jakeschincariol/day-trader-skill**

★6.4k · Python · 近期趋势

给 Claude 加 11 个炒股技能，帮你扫图、盯新闻、找买卖点，还能先模拟复盘。

**核心亮点**

- 一次扫描上千张走势图找机会
- 盯住你关注的股票突发新闻
- 下单前用历史数据模拟一万次看胜率
- 默认只做模拟盘，不会自动下单

**应用与部署指南**

免费、不用注册也不用 API Key，数据来自公开渠道。在 Claude 里粘贴仓库地址说 install skill，或在 Claude Code 里用插件命令安装。

- [ ] 打开 Claude 或 Claude Code
- [ ] 在 Claude 里粘贴仓库地址并说 install skill
- [ ] 或在 Claude Code 执行 /plugin marketplace add Jakeschincariol/day-trader-skill
- [ ] 再执行 /plugin install day-trader-skill@day-trader-skill

```bash
/plugin marketplace add Jakeschincariol/day-trader-skill
```

[查看仓库](https://github.com/Jakeschincariol/day-trader-skill)

**omnivore-app/omnivore**

★16.4k · TypeScript

开源的「稍后读」工具，把网页、邮件简报和 PDF 存起来慢慢读、做标注。

**核心亮点**

- 高亮、笔记、搜索和分享
- 自动记住长文读到哪里
- 支持 PDF 和邮件简报订阅
- 有 iOS、安卓和浏览器插件

**应用与部署指南**

官方云端服务已于 2024 年 11 月停止，现在需要自己搭服务器。README 只给出自托管指南链接，没有直接可复制的安装命令，需要按指南部署。

- [ ] 准备一台服务器和 Docker 环境
- [ ] 参照 README 里的自托管指南部署服务
- [ ] 在手机或浏览器插件里登录使用

[查看仓库](https://github.com/omnivore-app/omnivore)

**Graphify-Labs/graphify**

★145k · Python

把整个代码库连同文档、PDF 变成一张可查询的关系图，让 AI 助手少翻文件。

**核心亮点**

- 代码在本地解析，不上传不外传
- 每条关联都标明是直接读到还是推断的
- 用提问和追踪路径代替逐个搜文件
- 文档、PDF、图片也能一起纳入

**应用与部署指南**

在 Claude Code、Cursor、Codex 或 Gemini CLI 里输入 /graphify 即可使用。代码解析完全本地，文档和图片部分会用到助手模型或你配置的 API Key。

- [ ] 打开 Claude Code、Cursor、Codex 或 Gemini CLI
- [ ] 在对话里输入 /graphify
- [ ] 按提示让它扫描你的项目

[查看仓库](https://github.com/Graphify-Labs/graphify)
