# GitHub 热门效率与 AI 工具

*让 AI 助手更省钱、记性更好，也让视频和游戏内容能被拆解复刻。*

**R0Y00/Xbox2Windows**

★2k · Python · 近期趋势

研究把 Xbox Series X|S 游戏代码翻译成 Windows 电脑能跑的程序，目前还在实验阶段。

**核心亮点**

- 把部分 Xbox 机器码翻译成 C++ 代码
- 把部分游戏着色器转成电脑显卡格式
- 不用装游戏也能跑公开的测试程序
- 在 RTX 4060 笔记本上验证过画面一致

**应用与部署指南**

这是研究型项目，不是给普通玩家的成品。README 只说明可以在 Windows 上构建并运行 GPU 检查，完整游戏启动尚未验证，需要自己按仓库说明编译。

- [ ] 准备 Windows 电脑和 Python 环境
- [ ] 按 README 的 Build on Windows 章节自行构建
- [ ] 运行仓库提供的 GPU 检查测试

[查看仓库](https://github.com/R0Y00/Xbox2Windows)

**JuneYaooo/rea-video**

★13.4k · Python · 近期趋势

把任意视频逐个镜头拆开，判断是实拍、AI 生成还是代码做的，并告诉你怎么复刻。

**核心亮点**

- 逐镜头分析视频来源与拍摄手法
- 输出统一的 VIDEO.md 拆解文件
- 给出复刻该视频的做法建议
- 可作为插件接入 Claude Code、Codex

**应用与部署指南**

需要先装好 ffmpeg 和 Python 3.10 以上，然后在能执行命令的 AI 助手里让它安装本仓库并分析你的视频文件；也可以作为插件装进 Claude Code 或 Codex。

- [ ] 先安装 ffmpeg 和 Python 3.10+
- [ ] 在 AI 助手里让它安装本仓库
- [ ] 把视频路径交给助手开始拆解
- [ ] 或执行 `codex plugin marketplace add JuneYaooo/rea-video`

```bash
codex plugin marketplace add JuneYaooo/rea-video
```

[查看仓库](https://github.com/JuneYaooo/rea-video)

**omnivore-app/omnivore**

★16.4k · TypeScript

开源的「稍后读」工具，把网页、邮件通讯和 PDF 存起来慢慢读，还能划重点做笔记。

**核心亮点**

- 保存文章并自动记住阅读位置
- 划重点、写笔记、搜索和分享
- 支持 PDF 和邮件订阅文章
- 有浏览器插件和手机 App

**应用与部署指南**

官方云端服务已于 2024 年 11 月停止，现在需要自己搭服务器。README 指向自建服务器指南，适合有技术基础的人部署后配合浏览器插件和 App 使用。

- [ ] 阅读 README 中的自建服务器指南
- [ ] 按指南部署自己的 Omnivore 服务
- [ ] 安装浏览器插件或手机 App 连接使用

[查看仓库](https://github.com/omnivore-app/omnivore)

**JuliusBrussee/caveman**

★122.9k · Go

让 AI 编程助手少说废话、少读冗余内容，从而降低使用成本的工具。

**核心亮点**

- 原始内容仍可完整找回
- 把多个编程助手集中在一个窗口
- 可直接用你已有的订阅和密钥

**应用与部署指南**

提供 Mac 版应用可直接下载使用，也提供本地代理方式接入现有编程助手；README 未给出命令行安装方式，具体配置需看官方文档。

- [ ] 从官网下载 Caveman Code（Mac 版）
- [ ] 用已有的订阅或密钥登录
- [ ] 在设置中开启压缩选项

[查看仓库](https://github.com/JuliusBrussee/caveman)

**thedotmack/claude-mem**

★119.8k · TypeScript

给 AI 编程助手装上「记忆」，让它下次开工时记得上次做过什么，不用从头再来。

**核心亮点**

- 自动记录 AI 助手每次会话做的事
- 用 AI 压缩成要点供下次调用
- 下次会话自动带上相关背景
- 支持 Claude Code、Codex、Cursor 等

**应用与部署指南**

README 有 Quick Start 章节但摘录中未给出具体命令，需按仓库文档安装配置；装好后在你常用的 AI 编程助手里启用即可，部分助手只能搜索记忆、不记录会话。

- [ ] 打开 README 的 Quick Start 章节
- [ ] 按文档完成安装与配置
- [ ] 在支持的 AI 助手里启用记忆功能

[查看仓库](https://github.com/thedotmack/claude-mem)
