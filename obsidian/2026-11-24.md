# GitHub 热门效率与 AI 工具

*从游戏兼容、AI 绘画参考到录屏与提示词，帮普通人省力上手 AI 与创作。*

**ivall/xcl**

★1.6k · Rust · 近期趋势

让 Xbox 主机游戏能在 Windows 电脑上直接跑起来的兼容工具。

**核心亮点**

- 在电脑上运行 Xbox 游戏文件，不用模拟器
- 已实测《我的世界》预览版等可完整游玩
- 把主机画面代码转成电脑显卡能用的格式

**应用与部署指南**

面向有一定动手能力的玩家，需在 Windows 电脑上准备游戏文件并自行编译运行，README 未给出普通用户的一键安装方式。

- [ ] 准备一台 Windows 电脑和 Xbox 游戏文件
- [ ] 参考仓库内 HANDOFF.md 与设计文档了解用法

[查看仓库](https://github.com/ivall/xcl)

**anhao/ai-pose-gallery-zh**

★7.9k · TypeScript · 近期趋势

把日文 AI 绘画参考图库翻成中文，还能在线拼人像、服装和姿势。

**核心亮点**

- 上千组姿势、服装、人像参考图全中文
- 在线工作台自由组合人像服装姿势
- 可离线浏览，也能接入 ComfyUI 插件

**应用与部署指南**

打开在线演示网址即可浏览和拼图；想本地部署需先装 Node 环境，按 README 构建静态站点。

- [ ] 访问在线演示网址直接浏览图库
- [ ] 本地部署前先安装 Node 环境
- [ ] 按 README 说明构建并启动静态站点

[查看仓库](https://github.com/anhao/ai-pose-gallery-zh)

**alyssaxuu/screenity**

★19k · JavaScript

免费无时长限制的录屏工具，录完还能在画面上涂画标注。

**核心亮点**

- 录屏幕、某个区域、摄像头都不限时长
- 边录边在画面上画箭头写字做标注
- 可录麦克风和电脑内部声音

**应用与部署指南**

它是浏览器扩展，在 Chrome 应用商店安装后点开即可录制，无需装 Node 或 Docker。

- [ ] 在 Chrome 网上应用店安装 Screenity 扩展
- [ ] 点击扩展图标选择录制区域开始录屏

[查看仓库](https://github.com/alyssaxuu/screenity)

**Comfy-Org/ComfyUI**

★148.3k · Python

用拖拽连线的方式搭 AI 出图流程，在自己电脑上生成图片视频。

**核心亮点**

- 拖节点连线搭流程，不用写代码
- 支持图片、视频、3D、音频等多种生成
- 低配显卡也能跑较大的开源模型

**应用与部署指南**

提供 Windows、Linux、macOS 桌面版和便携包，下载安装即可本地使用；也可用官方云端版，无需自己配环境。

- [ ] 从官网下载对应系统的桌面版或便携包
- [ ] 安装后打开软件，加载现成工作流模板

[查看仓库](https://github.com/Comfy-Org/ComfyUI)

- [ ] 打开仓库网页直接浏览收集的提示词
