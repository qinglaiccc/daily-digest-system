# GitHub 热门效率与 AI 工具

*让 AI 帮你聊天、操作浏览器、写代码，或给应用搭好后端*

**jev-chat/jev-chat-jarvis**

★1.6k · Kotlin · 近期趋势

装在安卓手机上的聊天副驾，在微信、QQ 等 App 里帮你读懂对方并给出回复建议。

**核心亮点**

- 在微信、QQ、X 私信里读取当前对话
- 分析对方意图和危险等级，给出 3 条候选回复
- 一键把回复填进输入框，发不发由你决定
- 支持本地知识库和联系人档案，回复更贴合

**应用与部署指南**

需要一台安卓手机，安装这个 App 并开启系统无障碍服务，再填入自己的大模型接口密钥即可使用。聊天内容只在本机分析，不会自动发送消息。

- [ ] 准备一台安卓手机
- [ ] 安装 Jev 聊天助手 App
- [ ] 开启系统无障碍服务权限
- [ ] 填入大模型接口密钥
- [ ] 在聊天 App 中打开悬浮窗使用

[查看仓库](https://github.com/jev-chat/jev-chat-jarvis)

**Player-YN/BrowserKitten**

★2.9k · JavaScript · 近期趋势

装在 Chrome 里的网页助手，选中页面内容说出想要的结果，它帮你生成可编辑的办公文件。

**核心亮点**

- 在网页上选中内容后描述想要的结果
- 自动操作当前标签页完成网页任务
- 生成表格、文档等可编辑的办公文件
- 自带密钥，数据不经过第三方服务器

**应用与部署指南**

需要 Chrome 135 以上版本，把项目文件夹作为「已解压的扩展程序」加载进浏览器，再填入自己的 OpenAI 兼容接口密钥即可。没有构建步骤，改完文件点重新加载。

- [ ] 克隆仓库或下载 Release 压缩包
- [ ] 打开 chrome://extensions 并开启开发者模式
- [ ] 点击「加载已解压的扩展程序」选择该文件夹
- [ ] 打开侧边栏粘贴 API 密钥
- [ ] 在普通网页上发送任务

[查看仓库](https://github.com/Player-YN/BrowserKitten)

**feder-cr/aihawk_mcp_server**

★31.6k · Python

一个能自动上网的浏览器助手，用大白话告诉它要做什么，它替你去网页上操作。

**核心亮点**

- 用自然语言指挥浏览器自动完成网页操作
- 不易被网站识别拦截，减少验证码困扰
- 可作为插件接入 Claude Code 等编程助手
- 自带网页界面，左边聊天右边看浏览器实时操作

**应用与部署指南**

需要先安装 uv 工具，然后可以接入 Claude Code 等助手使用，或直接用网页界面并填入 OpenRouter 密钥。Windows 和 Linux 都有对应命令。

- [ ] 安装 uv 工具（Windows 用 PowerShell 命令）
- [ ] Linux 用户执行 curl 安装脚本
- [ ] 在助手中添加插件市场并安装 aihawk
- [ ] 或运行 uvx aihawk ui 并填入 OpenRouter 密钥
- [ ] 打开 http://127.0.0.1:8765 开始使用

```bash
uvx aihawk ui --openrouter-key sk-or-...
```

[查看仓库](https://github.com/feder-cr/aihawk_mcp_server)

**supabase/supabase**

★110.5k · TypeScript

一套开源的开发工具组合，帮开发者快速给网站或 App 搭好数据库、登录和文件存储。

**核心亮点**

- 提供托管的 Postgres 数据库
- 自带用户注册登录和权限管理
- 自动生成数据接口，支持实时订阅
- 提供文件存储和 AI 向量检索工具

**应用与部署指南**

面向开发者，可以注册官网在线使用，也可以自己部署。README 主要指向官方文档，没有给出本地安装命令，建议先访问 supabase.com/docs 查看。

- [ ] 访问 supabase.com 注册账号
- [ ] 在控制台创建新项目
- [ ] 按文档接入数据库和登录功能

[查看仓库](https://github.com/supabase/supabase)

**google-gemini/gemini-cli**

★107.1k · TypeScript

谷歌开源的命令行 AI 助手，在终端里直接向 Gemini 提问并让它帮你操作文件。

**核心亮点**

- 在终端里直接和 Gemini 对话
- 能读写文件、执行命令、联网搜索
- 个人谷歌账号每天可免费使用 1000 次
- 支持接入自定义工具扩展能力

**应用与部署指南**

需要先安装 Node.js，然后用 npm 全局安装或直接用 npx 运行。首次使用需登录个人谷歌账号，免费额度为每分钟 60 次、每天 1000 次。

- [ ] 安装 Node.js 环境
- [ ] 运行 npm install -g @google/gemini-cli
- [ ] 在终端输入 gemini 启动
- [ ] 用个人谷歌账号登录

```bash
npm install -g @google/gemini-cli
```

[查看仓库](https://github.com/google-gemini/gemini-cli)
