# GitHub 热门效率与 AI 工具

*今天这批项目覆盖终端效率、AI 应用搭建与面试准备，帮不同角色省时间。*

**govijr/terminal-mac**

★2.1k · Swift · 近期趋势

在终端里开一台独立 Mac 虚拟机，让 AI 助手操作它而不碰你的真电脑。

**核心亮点**

- 终端里直接看到并控制一台独立 Mac 桌面
- 虚拟机有自己的应用、文件和账号，不继承你的登录状态
- AI 助手操作时不动你真实鼠标和剪贴板
- 支持 Kitty、iTerm2 等终端内嵌显示画面

**应用与部署指南**

需要 Apple 芯片 Mac、macOS 14 以上，首次运行要联网从苹果下载系统镜像，并预留约 64GiB 磁盘空间；用一条安装脚本即可装好。

- [ ] 确认是 Apple 芯片 Mac 且系统为 macOS 14 或更高
- [ ] 首次运行需联网下载 macOS 镜像并预留磁盘空间
- [ ] curl -fsSL https://github.com/govijr/terminal-mac/releases/latest/download/get.sh | bash
- [ ] 用 Ghostty、Kitty 或 iTerm2 打开终端查看虚拟机画面

[查看仓库](https://github.com/govijr/terminal-mac)

**l0ng-ai/openidea**

★7.4k · TypeScript · 近期趋势

把 IntelliJ IDEA 那套操作习惯搬进一个更轻更快的本地代码编辑器。

**核心亮点**

- 沿用 IDEA 快捷键、工具窗口和全局搜索习惯
- 内置编辑器、调试器、Git、终端、数据库和 HTTP 客户端
- 支持 60 多种编程语言
- 提供 macOS、Windows、Linux 安装包

**应用与部署指南**

去项目发布页下载对应系统的安装包即可使用；Windows 用户也可选免安装压缩包，解压后运行 openidea.exe，无需额外装开发环境。

- [ ] 打开项目发布页下载对应系统安装包
- [ ] Windows 可解压便携包后运行 openidea.exe
- [ ] 按 IDEA 习惯的快捷键和工具窗口开始写代码

[查看仓库](https://github.com/l0ng-ai/openidea)

**jarun/nnn**

★22.1k · C

一个体积只有约 150KB、几乎不用配置的超快终端文件管理器。

**核心亮点**

- 在终端里浏览和管理文件，速度极快
- 能分析磁盘占用、批量重命名、挑选文件
- 插件可扩展实时预览、挂载磁盘、文件对比等
- 可在树莓派、安卓 Termux、Linux、macOS 等上运行

**应用与部署指南**

这是命令行工具，需要先按系统方式编译安装；装好后在终端输入 nnn 即可启动，几乎不用写配置文件。

- [ ] 按 README 的编译说明在系统上构建安装
- [ ] 在终端输入 nnn 启动文件管理器
- [ ] 按需安装插件扩展预览、挂载等功能

[查看仓库](https://github.com/jarun/nnn)

**langgenius/dify**

★160.6k · Python

一个开源的 AI 应用搭建平台，用可视化界面把大模型接进业务流程。

**核心亮点**

- 拖拽式搭建 AI 工作流和智能体
- 接入知识库让 AI 基于自己的资料回答
- 统一管理多种 AI 模型和工具
- 支持云端或自己服务器部署

**应用与部署指南**

推荐用 Docker 自建：机器至少 2 核 CPU、4GiB 内存，装好 Docker Compose 和 OpenSSL 后，在 docker 目录复制配置、生成密钥并启动服务。

- [ ] 确认机器至少 2 核 CPU、4GiB 内存
- [ ] 安装 Docker 与 Docker Compose v2.35.0 以上及 OpenSSL
- [ ] cd docker
- [ ] cp .env.example .env
- [ ] openssl rand -hex 32 并把结果填入 .env 的令牌项
- [ ] docker compose up -d

[查看仓库](https://github.com/langgenius/dify)
