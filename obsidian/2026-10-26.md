# GitHub 热门效率与 AI 工具

*从解压、绘图到本地跑 AI，帮普通人省磁盘、省打字、省时间。*

**xevrion/hatchzip**

★1.9k · Rust · 近期趋势

磁盘快满时也能解压大压缩包的工具，边解边删原包省空间。

**核心亮点**

- 解压时同步缩小原压缩包，只需留出解压后文件的空间
- 支持 ZIP、7z、RAR、tar 和分卷压缩包
- 中途停止或崩溃后能接着上次进度继续
- 提供桌面应用和命令行两种用法

**应用与部署指南**

从官网 hatchzip.dev 或仓库发布页下载对应系统的桌面应用即可使用，也有命令行版本；无需额外安装运行环境。

- [ ] 访问 hatchzip.dev 或仓库 Releases 页面
- [ ] 下载对应 Windows、macOS 或 Linux 的安装包
- [ ] 安装后打开桌面应用或使用命令行解压

[查看仓库](https://github.com/xevrion/hatchzip)

**wheresryan22/anatomy**

★20.6k · JavaScript · 近期趋势

让 AI 把抽象概念画成可交互的立体机械图，帮人看懂原理。

**核心亮点**

- 把技术概念变成可动的立体机械插图
- 生成带标题、提示和实时读数的图卡
- 支持鼠标和键盘操作让图动起来
- 输出 SVG 并可叠加 3D 光影效果

**应用与部署指南**

这是给 Claude 等 AI 编程助手用的技能包，需先有对应 AI 工具，再用一条命令安装，安装时会询问要接入哪个助手。

- [ ] 准备好 Claude Code、Codex 等任一支持的 AI 工具
- [ ] 运行 npx skills add wheresryan22/anatomy -g
- [ ] 按提示选择要接入的 AI 助手

```bash
npx skills add wheresryan22/anatomy -g
```

[查看仓库](https://github.com/wheresryan22/anatomy)

**espanso/espanso**

★14.7k · Rust

打字时自动把缩写替换成整段文字的工具，跨平台且数据只存本地。

**核心亮点**

- 输入关键词自动展开成常用句子
- 在几乎所有软件里都能用
- 支持表情、图片、日期和自定义脚本
- 内置搜索栏和插件包管理

**应用与部署指南**

需先从官网 espanso.org 下载安装对应系统版本，装好后编辑本地配置文件添加自己的缩写规则，全程离线不上传数据。

- [ ] 访问 espanso.org 下载对应系统安装包
- [ ] 安装并启动 espanso
- [ ] 编辑配置文件添加触发词和替换内容

[查看仓库](https://github.com/espanso/espanso)

**Comfy-Org/ComfyUI**

★142.9k · Python

在自己电脑上跑 AI 画图和内容生成的工具，用连线搭积木的方式组合流程。

**核心亮点**

- 用节点连线的方式搭建 AI 生成流程
- 在本机运行，不依赖云端服务
- 提供图形界面和接口两种用法
- 可自由组合和复用生成模块

**应用与部署指南**

需要本地有 Python 环境并自行安装依赖，适合愿意折腾的进阶用户；普通用户也可先看官网是否有更简单的桌面版本。

- [ ] 先安装 Python 运行环境
- [ ] 按 README 说明安装项目依赖
- [ ] 启动程序后在浏览器打开图形界面

[查看仓库](https://github.com/Comfy-Org/ComfyUI)

★134.5k · TypeScript

画手绘风草图的在线白板，适合画流程图和线框图，可多人协作。

**核心亮点**
